Greetings, Mercenary!
Below you will find a repository of information for the Gloomhaven board game.
Major Errata
Please read:
For First Printing (2025) copies, players should be aware of the following errata:
The
campaign sheet
has been revised to include key information about additional event cards that are unlocked alongside new classes. This information is as follows:
Add C-57 to the city event deck once you have at least 13 reputation with one faction.
Add the following cards to your event deck when each character is unlocked:
[Sun]: R-50, R-51
[Three Spears]: R-47, C-78
[Circles]: R-44, R-45
[Eclipse]: R-46, C-81
[Cthulhu]: C-76, C-77
[Lightning Bolt]: C-73, R-40
[Music Note]: R-49, C-80
[Angry Face]: C-74, C-75
[Saw]: R-48, C-79
[Triangles]: R-42, R-43
[Two Mini]: R-52, R-53
[Swords]: R-54
In scenario 26, monsters on tiles 2-D and 10-B should not be set up at the start of the scenario, with the exception of the City Archers located adjacent to the wall section overlays.

Crossover Character Sheets
You can find character sheets for all Frosthaven, Forgotten Circles, and Jaws of the Lion classes, both as images and a printable PDF, by following this link:
Crossover Character Sheets
In the case of Frosthaven, these new sheets provide space to track Gloomhaven resources. In the case of Forgotten Circles and Jaws of the Lion, they feature traits, masteries, and a re-balanced set of perks. Development of these was done by Drew Penn and Dennis Vögele.
Spoiler Note:
All locked Frosthaven classes have their files titled using their spoiler-shielded name, but there is some potential for class spoilers if you're not careful.
