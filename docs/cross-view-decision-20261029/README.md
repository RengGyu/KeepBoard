# 별도 촬영 사진 자동 정합: 지금 구현할지에 대한 판단

2026-10-29 · 연구 전용 · 제품 변경/모델 호출/새 시험 실행 0.

**권고: 지금은 범용 자동 정합을 구현하지 말고, 실제 같은 정지판의 독립 촬영 사진으로 추가 정보의 가치를 먼저 확인한다.** 현재 전체+crop 결합은 계속 사용한다. 별도 촬영은 crop으로 얻을 수 없는 해상도·반사 회피·가림 해소를 제공할 가능성이 있지만, KeepBoard에서 그 이득과 오연결 부담을 함께 측정한 자료는 아직 없다. 스캔을 여러 각도에서 훑어 자동으로 한 판에 합치는 것이 목표라면 결국 연결 수단은 필요하지만, 그것이 곧 범용 정합 엔진이어야 하는지는 미결정이다.

|특징점 기반 평면 정합 후 물체 연결|**정보 이득 확인 뒤 한정 검토**|평면 보드/타일 영역의 좌표 후보를 만들 수 있다. 입체 말·주사위의 시차, 반사, 반복 문양, 가림, 움직인 물체는 별도 문제다. 좌표 정합 성공은 실물 동일성/값 정답/상태 불변의 증명이 아니다.|

1차 근거(확인일 2026-10-29): [OpenCV 공식 homography 설명·구현](https://docs.opencv.org/4.13.0/d9/dab/tutorial_homography.html)은 평면 또는 특정 회전 조건의 영상 관계를 다룬다. 따라서 판 평면의 변환을 높이가 다른 모든 말의 박스에 그대로 적용하는 것은 부당하다는 것이 **KeepBoard 적용 추론**이다. [LightGlue 논문](https://arxiv.org/abs/2306.13643)과 [저자 구현](https://github.com/cvg/LightGlue)은 이미지 간 국소 특징점 대응을 제공한다. 게임 물체 정체성이나 수량을 반환하는 모델은 아니다. 해당 논문/구현의 속도·정합 성능을 KeepBoard, 폰, 현재 서버의 성능으로 전용하지 않는다. 이번에는 설치·추론하지 않았다.

## 4. 가장 작은 판별 시험 제안 — 실행하지 않음

**첫 정지판 1개·3요청으로 시작, 정보 이득이 보이면 다른 정지판 1개에서 같은3요청. 총 최대6요청, 자동 재시도0.** 첫 사례는 현재 generic 경로의 사그라다나 캐스캐디아 중 실제 촬영 가능한 게임으로 잡는다. 둘째는 첫 사례와 다른 공간/실물 특성으로 고른다. 두 사례도 일반성 증명이 아니며 Catan native 검증으로 대신하지 않는다.

### 입력 확보와 사전 고정

- 실물을 가진 사용자/협력자가 한 판을 멈춘 뒤 **W 전체사진 → D 같은 목표 영역의 독립 근접사진 → Wcheck 전체 확인사진**을 찍는 방식이 가장 명확하다. 본 연구는 연락·추가 촬영·API 전송을 하지 않는다. 연속 짧은 영상은 상태불변 확인의 로컬 보조 근거로만 쓰고 전체 프레임을 API에 보내지 않는다.
- D는 W와 대응할 주변 타일/판 경계도 포함한다. 기물을 옮겨 보이지 않던 값을 노출시키지 않는다. 판본·owner/공개범위·상태 동일 여부를 촬영자가 확인한다. Wcheck와 시각 대조해 움직임이 확인되거나 동일성을 판별할 수 없으면 해당 쌍은 제외한다. 같은 상태 자료를 얻지 못하면 이 부분은 **UNKNOWN**으로 남긴다. 인쇄물·디지털 변환·다른 게임 상태로 대체하지 않는다.
- 응답 전에 W의 목표 ROI를 정해 **C=W의 lossless crop**을 만든다. C와 D가 보는 실물 영역을 대응시키되 디지털 확대/합성으로 새 정보처럼 만들지 않는다. W/C/D SHA·crop 변환·입력 크기·모델/설정·허용 종류/속성을 고정한다.
- 사람이 직접 확인한 목표 영역의 물체 ID·사진별 실제 물체 박스·읽을 수 있는 속성/가려진 속성·사진 간 대응을 사전 동결한다. 일부만 확실하면 그 부분만 분모로 쓰고 나머지는 unknown. 과거 AI 부분 참조를 사람 정답으로 승격하지 않는다. 정답과 대응표는 모델 입력/자동 정합 입력에 넣지 않는다.

|조건|실제 요청|비교 질문|
|---|---|---|
|A single|W 1회|전체사진만으로 어떤 물체/값을 읽는가?|
|B same-source crop|A의 W 응답 재사용+C 1회|현재 구현된 crop 판독·결합으로 얼마나 보완되는가?|
|C independent capture|A의 W 응답 재사용+D 1회|원본 crop보다 별도 촬영이 유용한 물체/값을 추가로 제공하는가?|

같은 모델·task·출력 계약·추론/출력 한도를 유지한다. C/D는 같은 영역/속성 판독 지시로 맞추고 사진 및 필수 provenance 차이만 허용한다. W를 조건마다 다시 호출하지 않는다. 조건별1회이므로 모델의 실행 변동을 통제한 인과효과나 유의성을 주장하지 않는다. D는 해상도·시점·반사가 함께 달라질 수 있어 **독립 촬영의 실용 가치**를 시험하는 것이며, 각도 변화만의 인과 실험이 아니다.

### 결과를 서로 섞지 않을 것

1. **판독 이득:** 고정 목표 영역의 개별 물체 검출, 읽을 수 있는 속성 정답/오독/unknown, 누락·환각·중복을 분리한다. D가 B보다 새로 맞힌 값뿐 아니라 기존 정답을 악화시킨 값도 적는다. tile center 포함 여부로 숫자/물체 박스 정확도를 대체하지 않는다.
2. **정합 이득:** 현재 제품에 W+D를 넣은 실제 편집 가능 개체/값과 미연결 관측을 구분한다. 별도 계산으로 사람 대응표를 이용한 ‘정체성을 알았을 때 활용 가능한 상한’을 낸다. 이 상한은 자동 정합 성능이 아니다. 현재 자동 교차시점 연결은 미구현이므로 그 오연결률을 0%로 적지 않고 **N/A**로 적는다.
3. **시간·비용·사람 부담:** 각 요청 시간과 입력/출력/사고/총 토큰, 실제 동시 실행의 완료시간을 기록한다. 미보고 토큰은 unknown. 촬영·검수·정정 시간을 실제 재면 별도 기록하고 추정 클릭수/시간을 만들지 않는다. 병렬 실행은 토큰을 줄이지 않으며 30초 또는 절감률을 약속하지 않는다.

**후속 분기:** D의 유용한 추가 정보가 없거나 읽기 오류가 주원인이면 정합 개발은 보류한다. 몇 개 값만 보완되고 기존 정정/대상 지정이 충분하면 그 경로를 유지한다. 여러 물체의 유용한 관측이 반복해서 늘고 연결 작업이 실제 부담으로 확인될 때에만, 저장된 같은 사진쌍에서 평면 정합 후보1개를 무과금 오프라인으로 시험한다(추가 모델 호출 없음). 정합에 쓰지 않은 대응점/물체로 오연결·미연결·중복·좌표 오차·편집 가능한 회수량을 검사한다. 특징점이 많이 맞아도 반복 문양/입체물의 잘못된 연결이 남으면 자동 합산하지 않는다. 성공선을 임의의 정확도%로 만들지 않고 회수한 정보, 오류의 영향, 사람 부담을 함께 보고 다음 범위를 결정한다.

## 5. 인계 결론 — 8줄

1. 지금은 자동 정합 구현보다 진짜 같은 상태의 별도 촬영 시험을 먼저 권고합니다.
2. 여러 사진을 병렬로 읽는 기능은 있지만, 다른 각도의 동일 물체 자동 대응은 아직 없습니다.
3. 현재 확인된 이득은 같은 원본+crop의 편집 가능한 관측 회수이며 일반적인 다중시점 성능이 아닙니다.
4. 기존 캐스캐디아 대체사진은 상태가 달라 시험에 쓸 수 없고, 검증된 별도 시점 사진쌍은 아직 없습니다.
5. 한 정지판의 전체·원본 crop·독립 근접사진을 3요청으로 비교하고, 유용하면 다른 판에서 3요청만 추가합니다.
6. 추가로 맞힌 물체/값, 오독·중복·오연결, 대기·토큰·사람 정정 부담을 따로 봅니다.
7. 새 사진이 충분한 정보를 더 주고 수동 연결이 부담일 때만 평면 영역에 한정한 정합을 검토합니다.
8. 그전에는 현재 crop 결합·원사진 보존·선택 정정을 유지하며, 저장을 막는 확인 단계를 늘리지 않습니다.
