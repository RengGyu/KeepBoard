# KeepBoard 초기 게임 선정안

조사 기준일: **2026-10-21**. 제품 코드·사용자 저장판은 변경하지 않았다.

**1천·5천·1만 종 중에서는 기본 게임 1,000종을 준비 카탈로그 규모로 권한다. 실제 초기 시험 목표는 총 60종, 먼저 24종(기존 카탄 포함), 이어서 36종이다.** 넓게 검토한 기본 게임 후보 120종을 실제 목록으로 남겼고, 나머지 60종은 요청을 받아 올린다. 1,000종은 확대 목표이며 이번에 확보한 목록 수가 아니다. 이 숫자는 시장 점유율로 계산한 최적값이 아니라, 인기작의 폭·저장 가치·공통 화면 재사용을 함께 고려한 **권고**다. 출시 날짜나 게임별 개발시간을 측정한 수치는 아니다.

추가 요청에 따라 **확장도 기본팩+확장패치+세션 커스텀 맵으로 지원하는 설계**를 포함했다. 이 카탈로그의 120행과 확장 제외 메모는 기본 프로필의 범위를 뜻하며, 확장을 영구 제외한다는 뜻이 아니다. 확장/판본을 기본 게임 수에 중복 계수하지 않는다. [규모 비교·확장·가변 지도·용량 상세](scale-and-expansions.md)

**시험 완료로 보고받은 게임은 현재 카탄 1종뿐이다(REPORTED).** 이번 조사에서 재시험하지 않았다. 나머지 119종은 선정 후보이며, 목록 등재·공식 규칙 공개·사진 기록 가능성은 지원 완료와 다르다. 초기 목표 60종은 카탄 외 59종을 준비하는 뜻이다.

## 왜 60종인가

24종만 고정하면 가족·카페 이용층과 장시간 전략·협력층을 함께 담기에 좁다. 반대로 120종 모두에 전용 배치와 카드 사전을 먼저 만들면, 게임별 명세 관리가 다시 목표가 된다. **60종에서 공통 사진·간단 정정·저장한 판 보기의 폭을 확보하고, 추가 요청이 생기는 게임의 작은 정의만 더하는 방식**이 적합하다.

초기 60종은 공용 지도 16, 가변 타일 5, 개인 격자 7, 카드 배열 8, 일꾼/경제 12, 협력 6, 캠페인 4, 비밀 정보 중심 2종이다. 이는 편집 화면 재사용을 위한 주된 상태 유형 분류이며, 게임의 장르나 실제 테이블 크기를 측정한 통계가 아니다. 47종은 사진 공통 또는 작은 배치 프로필을 우선 권고하고, 13종은 필요할 때만 전용 연결/부착/장기 기록을 보탠다. 전용 확장이 필요한 게임에도 전체 규칙 엔진을 만들지 않는다.

짧다고 전부 제외하지 않았다. 아줄·스플렌더·루미큐브처럼 이용 근거가 있거나 개인 배치를 다시 맞추기 번거로운 게임을 포함했다. 반대로 도블·할리갈리·저스트 원 등은 후보로 확보하되 요청 대기다. 초기 60종 중 공식 상한이 45분 이하로 확인된 것은 9종, 하한이 90분 이상인 것은 14종이다. **시간 미확인 17종과 인당 시간 2종이 있어 이를 전체 비중처럼 해석하면 안 된다.**

시간과 크기도 따로 판단했다. 패치워크는 공식 30분이지만 개인 격자 위치 보존이 중요하고, 트와일라잇 임페리움 4판은 공식 240–360분에 지도·함대·개인 카드가 함께 남는다. 작은 카드게임도 손패 순서가 중요할 수 있다. 카드 더미 내부 순서, 가려진 내용, 앱 내부 진행은 사진 한 장에서 복원할 수 있다고 약속하지 않는다. [패치워크 공식 제품](https://www.lookout-spiele.de/en/games/patchworkre.html), [TI4 공식 제품](https://www.fantasyflightgames.com/product/twilight-imperium-fourth-edition/)

인원 또는 시간을 담은 75종 중 **직접 열린 공식 페이지 근거 23종, 공식 검색 색인 근거 49종, 기존 연구 재사용 3종**이다. 직접 페이지를 모두 확인했다고 주장하지 않는다. JSON의 `sources` 102개에는 각 URL의 접근 상태와 확인 내용을 적었다. `checked_at`은 이번 조사/재검토일이며 게시일·판본 발매일이 아니다. 검색 색인은 본문보다 최신성이 약하므로, 해당 게임을 실제 시험할 때 추천 판본과 다시 맞춘다.

공식 시간은 설명 학습·초보자 숙고·사진 촬영 시간을 더한 실측 시간이 아니다. 미확인 값은 JSON `null`, CSV 빈칸으로 남겼다. 아르낙·카베르나·SETI는 인당 시간, Sleeping Gods의 10–20시간은 전체 캠페인 값으로 분리했다. 판본/표기 차이도 보존했다: 윙스팬의 공식 페이지 안 시간 불일치, 오를레앙 현행 8쇄의 2–5인, 아컴호러 카드게임 2026 AHC100과 기존 2021 AHC60, 메이지 나이트 기본판과 확장 포함 UE, 글룸헤이븐 2판의 `1–2+시간` 등이다. 출처와 선택한 값은 각 행의 메모에서 확인할 수 있다.

## 지원 범위와 제작량

지원 목표는 **기본판 사진 → 공용판과 필요한 개인 보유 확인 → 쉬운 정정 → 저장/재열기**다. 점수 자동 계산, 모든 카드 효과, 행동 적법성, 숨은 덱 순서, 완전한 실물 복원은 기본 지원 조건에 넣지 않는다.

| 기록 방식 | 새 게임에서 준비할 것 | 하지 않을 것 |
|---|---|---|
| A `photo_common` | 게임명·판본·공용 사진, 필요한 부품 이름과 수동 수량/메모, 개인 정보 구역 | 게임마다 전용 화면·전체 카드 사전 만들기 |
| B `small_layout_profile` | A 위에 필요한 격자/지도 자리, 부품 방향·소유 등 소수 항목 | 전체 행동/승리/보존 규칙을 강제하는 팩 |
| C `optional_special_extension` | 실제 정정에 필요한 연결·부착·특수 개인 상태만 선택 추가 | 모든 숨은 진행을 추정하거나 전체 엔진으로 확대 |

이는 **권장 구현 방식**이지 현재 A/B/C 범용 화면이 120종에서 작동한다는 의미가 아니다. [기존 온보딩 연구](../../lightweight-game-onboarding.md)와 [카탄 비교 실험](../../lightweight-catan-trial/full-review.md)에서 작은 관측 팩만으로는 카탄의 자리·항구·개인 필드를 대체하지 못했다. 카탄 기존 기능을 유지하고 공통 사진 정정 경로를 먼저 재사용해야 한다. 모든 게임을 2.7KB 또는 5필드로 끝낼 수 있다는 약속도 하지 않는다.

게임당 첫 초안은 **관측할 부품 4–8종, 필요한 개인 수량 0–4개를 목표 범위**로 잡고, 사진/짧은 메모로 충분한 값은 필수 질문으로 만들지 않는다. 이는 작성량 가이드이며 조사 결과로 입증한 작업시간이나 강제 상한은 아니다. 그래픽은 공통 아이콘과 사용자가 제공한 실제 사진 영역을 우선한다. 공개 규칙 링크가 있다고 전체 카드 그림의 재배포 권리가 생기는 것은 아니다.

지원 게임 수는 독립 기본 게임 단위로 센다. 언어판, 프로모, 재질판, 같은 게임의 개정판, Big Box 안 확장은 추가 종수로 세지 않는다. 팬데믹 레거시 시즌 1 Red/Blue는 1종이다. 사자의 턱·프로스트헤이븐·듄 업라이징·7 Wonders Duel은 독립 실행 게임이므로 각각 세었다. 티켓 투 라이드 북미만 이 목록의 기준이며 유럽을 별도로 세지 않았고, 북미 자리와 호환된다고도 하지 않는다. LCG도 지정 기본 상자에서 시작해 요청된 확장을 별도 패치로 더한다. 모든 추가 카드의 자동 해독, TCG 전체 카드 풀, TRPG 및 독립 미니어처 워게임 전반은 초기 범위 밖이다.

## “이 게임 추가해주세요” 운영

사용자에게 먼저 받을 필수값은 **게임명 하나**다. 판본은 “모름”을 허용하고, 가능하면 상자/판 사진 한 장 또는 공식 규칙 링크를 받는다. 처음부터 규칙·부품 목록을 작성하게 하지 않는다.

1. 기존 ID·별칭과 대조하고 판본인지, 확장인지, 독립 게임인지 짧게 확인한다. 판본은 같은 ID의 프로필, 확장은 부모 게임에 붙는 버전 있는 패치로 연결한다. 커스텀 맵은 새 게임 등록 없이 해당 세션에 저장한다.
2. 현재 공통 템플릿으로 게임명·사진 구역·부품·개인 수량의 작은 초안을 만든다. AI 후보 생성은 선택 가능하지만 코드 형식 검사와 사람이 판본/비밀 범위를 확인한다. 이번 조사에서는 AI를 호출하거나 팩을 생성하지 않았다.
3. 요청한 사진에서 보이는 상태만 자동 초안으로 담고, 위치/색/수량/누락을 사람이 고친 뒤 저장·재열기해 같은 값이 남는지 확인한다. 개인 정보는 소유자 범위로 두고, 사진에 없는 값은 모름/메모로 둔다.
4. 해당 범위가 확인됐을 때만 `tested`로 올린다. 후보 목록만 있을 때는 `catalogued`, 초안만 있으면 `profile_draft`로 둔다. 시나리오 사이만 시험했다면 전투 중까지 시험했다고 표시하지 않는다.

실제 요청과 사용 가능한 사진이 있고 공통 UI로 담을 수 있으면 P3나 목록 밖 게임도 P2보다 먼저 진행할 수 있다. 독립 전용 기능이 필요한 요청은 그 차이만 표시하고 사진 기록부터 제공한다. 반복 요청은 같은 ID로 합치며, 사전 인기 점수나 게임별 대형 규칙 사전을 만들지 않는다.

## 파일 계약과 검증

JSON은 `games` 120행과 `sources` 출처 사전을 포함한다. 각 게임에 ID·한글/영문명·추천 판본·인원/시간·출처·인기 근거·핵심 저장 요소·기록 방식·단계·선정 이유·자료 가용성·미확인을 넣었다. `allowed_player_counts`가 있으면 min/max보다 우선한다. 예를 들어 듄 업라이징의 공식 인원은 1–4명 또는 6명이며 5인은 포함되지 않는다. `table_shape_category`는 제안한 구도 분류이고 실제 면적 측정값이 아니다. CSV는 UTF-8 BOM, 배열은 JSON 문자열, 숫자 미확인은 빈칸이다. 조사용 카탈로그이며 제품 게임팩에 그대로 등록하는 파일이 아니다.

`build_catalog.py`는 수집된 짧은 사실과 수작업 선정 행에서 파일을 다시 만든다. `verify_catalog.py`는 120개 고유 ID, 24/36/60 분류, 기본판 플래그, 출처 연결, 시간/판본 예외, CSV/JSON 동일성을 확인한다. 검증 결과는 [validation.json](validation.json)에 있다. 웹 정보의 최신성이나 게임의 실제 인식 품질을 자동 검증하는 테스트는 아니다.

```sh
python3 docs/research/initial-supported-games/build_catalog.py
python3 docs/research/initial-supported-games/verify_catalog.py
python3 docs/research/initial-supported-games/calculate-capacity.py
node --import tsx docs/research/initial-supported-games/measure-capacity.mts
```

남은 불확실성은 국내 현행 재고/판본, 56종의 공식 시간, 출처가 제품군/카페 이름에 그친 일부 항목, 카탄 외 실사진 시험이다. 이 빈칸을 임의 수치로 메우지 않고, 실제 추가 요청을 처리할 때 필요한 항목부터 확인한다.
