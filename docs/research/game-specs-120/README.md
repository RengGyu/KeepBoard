# 120종 핵심 게임 연구명세

2026-10-21 기준 **확정 카탈로그 120개 ID 모두 핵심 연구 초안을 작성했다.** 게임별 구성물, 실제 배치의 기준점·방향·연결, 공용/개인/비밀 상태, 중단 지점, 인식·정정 대상, 확장 경계와 미확인 항목을 담았다. 카탈로그의 이름·시간·선정 이유를 명세로 복사한 자료가 아니다.

**작성 완료 120종 / 미작성 0종 / 형식 유효 120종. 공식 규칙 전체 검증 완료와 이 패키지의 제품 통합·실사진 시험 완료는 각각 0종이다.** 기존 카탄 제품의 동작 여부와 이번 연구 패키지의 검증 범위는 별개다.

2026-10-22 저장·재개 보완: [120종 전수 결과와 변경·보류 기록](../../game-essentials/README.md). 공식 근거 특정 절을 확인한21종의 추가/보완과 앱 보관 권고를 구분했다. 아래 주 출처 수준 집계와 기존 coverage/source-index/validation은 최초 작성 시점 자료이며 최신 출처·해시·검사는 위 보완 manifest를 우선한다.

## 출처를 읽는 방법

| 주 출처 확인 수준 | 게임 수 | 의미 |
|---|---:|---|
| `rules-text-partial` | 6 | 공식 규칙 본문을 열고 관련 부분 확인. 전 규칙 검증은 아님 |
| `rules-index-partial` | 38 | 공식 규칙/FAQ의 검색 색인에서 일부 내용 확인. 원문 전체 열람으로 세지 않음 |
| `product-text-partial` | 20 | 공식 상품·소개 본문 확인. 그 소개가 다루지 않은 규칙은 미확인 |
| `product-index-partial` | 55 | 공식 상품의 검색 색인에서 확인. 카드별 효과·세부 규칙 검증은 아님 |
| `prior-research-reused` | 1 | 카탄의 기존 연구와 전달받은 상세 계약 재사용 |

규칙 본문을 직접 확인한 6종은 한나비·슬리핑 갓즈·황혼의 투쟁·한자 토이토니카·언더워터 시티즈·블로커스다. 추가 보조 출처가 있는 게임은 해당 JSON의 `sources`를 함께 본다. `checked_at`은 이번 확인일이며 규칙의 발행일이나 최신 개정일이라는 뜻이 아니다. 검색 색인은 현재 링크의 직접 다운로드 성공을 보증하지 않는다.

각 항목의 `confidence`가 파일 전체 평가보다 우선한다.

- `verified`: 연결된 출처의 확인한 범위에서 해당 주장만 확인했다.
- `reported`: 출처에서 소개되거나 기존 자료에서 전달된 내용. 전문·선정 판본의 전체 대조가 끝난 것은 아니다.
- `unclear`: 근거가 부족한 구성/규칙 후보. 구현에서 확정 사실로 쓰지 않는다.
- `recommendation`: KeepBoard의 저장·정정 설계 제안. 공식 게임 규칙으로 읽지 않는다.

수량을 모르면 `quantity: null`이고 빈자리·0과 다르다. 구성물 수량/좌표/카드 효과를 미확인 상태에서 만들어 채우지 않았다. 실제 표준 수량과 인식된 현재 수량도 다른 개념이다. 46종에 `unclear` 구성물 또는 규칙이 있고, 그 항목 ID는 `coverage.json`과 각 파일에 명시했다. 나머지 게임도 공식 규칙 전체 검증 완료로 세지 않는다.

## 명세가 담는 범위

현재 게임 파일에는 구성물 분류 437개, 상태 필드 1,360개, 규칙/기록 제안 408개가 있다. 공통 차례·메모 필드도 포함한 구조 규모이며, 모두 사실 검증을 마친 규칙 수라는 뜻이 아니다.

카탄은 [기존 상세 계약의 연구용 사본](authoring/catan-detailed-baseline.json)에 있던 **57필드·25조건부 요구·17도출·8보존 절차**를 유지했다. [카탄 명세](games/catan.json)는 여기에 원본 보존·배치층·가변 지도 경계의 연구 메모를 더한다. 원래 제품 팩을 수정하지 않았다. 조건부 요구는 참고 정보이며 입력을 끝내야 저장하게 하는 게이트가 아니다.

나머지 게임은 필요한 차이에 따라 분량이 다르다. 예를 들어 카르카손은 타일 내부 들판 연결, 쓰루 디 에이지스는 카드별 큐브와 은행 분포, 한자 토이토니카는 개인 공급/공용 재고, 에이언즈 엔드는 버림 순서, 캠페인 게임은 누적 기록과 현재 시나리오 상태를 구분한다. 모든 게임에 카탄의 57필드나 고정 19칸을 요구하지 않는다.

`resume.required_field_ids`와 `must_ask_field_ids`는 비워 두었다. 모름·나중에·그대로 저장을 허용한다. 기록 정정은 실제 게임 행동이 아니며 비용·득점·생산·다음 턴을 자동 수행하지 않는다. `lifetime=turn/round/campaign`도 재열기 때 값을 지우라는 명령이 아니다.

공용 사진과 소유자 정보는 별도다. 한나비의 `own-hidden`, 코드네임·아발론·제국의 습격 등의 역할별 정보는 단순한 `owner`와 구분한다. 이 분류가 현재 앱의 권한 UI까지 구현했다는 뜻은 아니다. 비밀 카드·덱 순서·스포일러를 명세 작성 때문에 펼쳐 수집하지 않는다.

## 후속 구현 전에 특히 볼 부분

| 항목 | 확인한 문제와 처리 |
|---|---|
| 아크스·다빈치 코드 | 공식 상세 규칙 텍스트 확보가 부족하다. 게임별 기록 후보는 작성했지만 세부 규칙/구성은 `unclear` 유지 |
| 아컴호러 카드게임 | 카탈로그는 2026 Chapter Two AHC100. 옛 코어를 자동 대체하지 않으며 새 원문 규칙의 배치/공개성 대조 필요 |
| 사그라다 | 원 기본판 규칙을 참고했다. 현행 Remastered와의 차이를 미확인으로 남겼으므로 실제 지원 판본을 선택해야 함 |
| 한자 토이토니카 | 공식 PDF에서 추출된 Bank 단계 텍스트가 2쪽과 4쪽에서 상충한다. 단계 수치를 강제하지 않고 실제 인쇄/정오표 확인 필요 |
| 블로커스 | 실제로는 네 색이 공유하는 하나의 판이다. 카탈로그의 개인 격자 표현을 그대로 구현하지 말 것. 색과 실제 담당자를 분리 |
| 에이언즈 엔드 | 공식 물리판 상품과 허가된 디지털판 제작자 설명을 구분했다. 비셔플/균열 세부의 물리판 전문 대조가 남음 |
| 앱·캠페인 게임 | 원래 앱 세이브/실물 캠페인 기록을 계속 유지. 사진 저장이 외부 앱 진행·미공개 분기를 복원하지 않음 |

자유 배치·가변 타일·다층 보드·순서 있는 더미는 `layout.areas`와 `anchor_contract`로 표현한다. 다음 요구는 현재 공통 스키마의 텍스트/JSON 계약으로는 기록 가능하지만 실제 장면 어댑터가 더 필요하다.

- SETI: 원판별 각도와 부모 층의 로컬 좌표. 전체 사진 회전과 내부 원판 회전을 분리.
- 팔레오: 그룹 ID와 복수 담당 플레이어의 연결. 그룹 수를 사람 수와 같게 만들지 않음.
- 루트·아나크로니·캠페인: 비대칭 세력/모드별 개인 상태, 순서·사용 면·일시 효과.
- 카르카손·캐슬 오브 매드 킹 루드비히: 타일 내부 기능 영역/문 접점·방향. 중심 좌표만으로 연결 확정 금지.
- 블로커스·갤럭시 트러커: 조각의 다중 점유 칸/회전/반사 또는 부품별 사방 연결구와 부착 물품.

확장은 `extensions: []`로 두고 `gaps`에 필요한 의존/추가 상태를 게임별로 적었다. 실제 확장 패치를 검증해 만들었다는 주장은 하지 않는다. 커스텀 기록 허용은 공식 합법 배치 승인과 다르다.

## 인계와 재검사

먼저 대상 게임의 `edition`·출처 `note`·`gaps`를 읽고 관측 배치/공개 상태부터 어댑터에 연결한다. `unclear`를 강제 규칙으로 실행하거나 모든 항목을 사용자 질문으로 바꾸지 않는다. 게임별 두 수용 예시는 [coverage.json](coverage.json)에 있으며 실제 실행한 테스트 결과가 아니다.

```sh
python3 docs/research/game-specs-120/authoring/build.py
node --import tsx tools/game-specs/cli.ts validate docs/research/game-specs-120/games --complete
node --import tsx tools/game-specs/cli.ts coverage docs/research/game-specs-120/games
```

이번 실행의 두 CLI는 exit 0, `present=120`, `missing/unknown/duplicate=[]`, `factualVerification=false`였다. 앱 실행·실AI·실사진·제품 테스트를 수행한 것으로 확대 해석하지 않는다. 제품 코드·기존 게임팩·개인 자료는 이 작업의 변경 대상이 아니었다.
