## 같은 분모의 관측과 편집 결과

B의 medium 참조 두 위치는 모름/D는 읽힌 값, D의 high 참조 다른 두 위치는 모름/B는 읽힌 값이었다. 기존 결합기가 서로 보충해 19개가 참조와 일치했다. 두 관측에서 공통으로 틀린 1개는 그대로다. high-confidence 숫자 18개만 보면 B 17맞음·1오독, D 15맞음·1오독·2모름, 최종 17맞음·1오독이다. 새 최종 19/20은 이전 A 전체-low 단독과 같은 수치다. 한 번씩의 반복 개발사진 결과로 high의 일반적 우월성이나 인과효과를 주장하지 않는다.

카르카손 색의 strict 문자열 점수는 B 및 최종 7/10, D 9/10이지만 pink/red 표현 3건을 확정 오독으로 간주하지 않는다. B+D의 공간 중복 후보 7건은 기존 B에서 온 것이다. 이전 직접 검토에서 3건은 정상 타일+말 겹침, 4건은 인접 타일과 거친 참조박스의 겹침이었다. 실제 중복 7개로 확정하지 않았다. D의 공간 후보 1건 역시 중복 물체 확정 수가 아니다. 티켓의 별도 group-surface 0/8은 개별 객차 25개와 다른 묶음 표현 평가이며, 8개 실물 추가 누락으로 합산하지 않는다.
