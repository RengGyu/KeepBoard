## 즉시 실행하는 최소 패키지

[구현 카드](implementation-card.md)를 구현솔에게 먼저 전달했다. `server/observationFusion.ts`의 증거/활성 경쟁자 분리부터 시작한다. 묶음 표면 연결·종류 충돌은 같은 원본의 실제 근거와 작은 회귀로 제한하며, 범용 정합이나 새로운 재조정 엔진을 추가하지 않는다. 원문·미배치·unknown·수동 null/0·삭제·소유/epoch 보호를 유지한다.

기존 구현솔 산출물은 [implementation/](implementation/)에 별도 저장된다. 이 디렉터리의 worker 결과는 독립 확인 전에는 **REPORTED**다. 독립 재생 결과와 남은 실패는 후속 보고에 기록한다.

## 보충 판독과 다음 검증

항상 whole+crop을 요구하지 않는다. 기존 관측에서 `unknownReason`, 실제 묶음, 속성 충돌, 경계 잘림을 구분하고, 작은 글자가 원본에 남아 있는 경우와 실제 새 근접 촬영이 필요한 경우를 나눈다. 반환 행이 없다는 이유만으로 게임 재고나 예상 개수를 넣지 않는다. 사전 관측이 없는 물체는 unknown 목록만으로 찾아낼 수 없다는 한계도 유지한다.

새 평가 입력은 기존 사용 사진과 다른 SHA의 독립 장면으로 선정하고, 원본 존재·노출 이력·관측 단위·가독성·부분 기준을 출력 전에 고정한다. 동일 사진의 crop/업스케일은 holdout으로 세지 않는다. 이전 결과를 보고 다시 튜닝한 입력은 개발 자료로 재분류한다. 새 카르카손·사그라다·티켓 투 라이드 3장과 선택 ROI의 AI 부분 기준 62물체, 별도 가시 묶음 8개를 출력 전에 동결했다. A 전체-low / B 같은 전체-medium / C 같은 원본의 crop-low, 최대 9회·peak2·retry0·계산 예산 $2다. 실제 청구 상한 보장은 아니며, 현재 자동 승인 검토의 직접 승인 확인 실패로 호출은 0회다. [입력](selection.json), [평가 계약](evaluation-preflight.json), [요청 동결](preflight.json), [차단 상태](approval-block.json).

ECC `eval-harness`의 사전 기준 고정·capability와 regression 분리 원칙만 사용한다. 예시 합격률·반복 횟수·별도 플랫폼은 이번 요구에 추가하지 않는다.
