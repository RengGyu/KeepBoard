# Terra 첫 품질 반복 — 독립 최종 검토

**결합 보완 패키지는 검토 범위에서 인계 가능하다. 판독 품질 개선 전체가 끝난 것은 아니다.** 제품은 구현솔이 수정했고 연구자는 설계·합성 경계·기존 실제 응답 재생을 담당했다.

## 직접 확인한 결과

동결 1차 preimage와 최종 delta3 소스를 대조하고, 같은 기존 20개 실제 응답·동결 AI 부분 기준으로 재생했다. **개별 회수 103→104/147**: 카르카손 20→21/31이며 다른 9게임은 동일하다. raw **341개**가 그대로 남고 완료순서 역전·동일 단위 재전달도 같다. 일치 가능한 기준 안의 오연결은 0이지만 기준 밖 연결은 미확인이다. 이는 전체 사진 정확도나 새 독립 사진의 일반화 결과가 아니다. [재생 집계](independent-final-scores.json), [최종 확인·소스 해시](independent-final-review.json).

다음 네 합성 경계는 직접 재생해 수정 전 문제와 수정 후 해결을 확인했다. 사진 판독 실측과 별개다. [재현 코드](independent-boundaries-final.mts), [결과](independent-boundaries-final.json).

1. 같은 가시 묶음으로 연결된 두 관측을 중복 부모로 세지 않아, 뒤의 개별 관측을 회수한다.
2. 이미 분해한 묶음이 다음 job에서 다시 보이더라도 부모+자식이 이중 편집물로 늘지 않는다. 원관측·부분 상세화 관계와 미확정 잔량은 유지한다.
3. 묶음 수량 2와 4처럼 알려진 값이 다르면 기존값을 유지하고 선택적 근거에 차이를 표시한다. 합산·숨은 수량 추정·null→0 변환·필수 확인 단계는 없다.
4. 재등장한 부모에는 실제 대응하는 자식만 관련 항목으로 연결한다. 다른 묶음의 자식까지 표시하던 메타 오류도 좁게 수정했다.

고정 기하 기준을 사진에 맞춰 조정하지 않았고 게임별 답·좌표·개수 특례를 추가하지 않았다. 수동 수정·삭제·null/0, 다른 원본/소유/epoch 보호는 기존 focused 검사와 코드 경계에서 확인했다. 연구자 직접 실행은 합성 경계 및 delta2 focused **18/18**, 실제 응답 오프라인 재생이다. 구현솔의 최종 **47 focused / 2 loopback / type·build exit0**, delta2 실제 mock HTTP 저장재개 **10/10**은 별도 **REPORTED**다. delta3 전체10 HTTP 재실행으로 확대하지 않았다.

## 해결하지 못한 품질

- Quacks의 종류 간 물방울 중복 1건은 남는다. 같은색·겹침만으로 무조건 병합하거나 사례에 맞춰 임계값을 낮추지 않는다.
- Dominion/Ticket의 묶음 표면 정보는 개별 물체 복원과 다르다. 선택 기준에서 개별0이더라도 유용한 표면 이름/색까지 없다고 취급하지 않는다.
- 처음부터 미검출된 물체, 숫자 오독, 원사진에 없는 정보는 결합 코드로 만들 수 없다. 사용자 수정 시간과 실제 실물 복원 성공도 미측정이다.

## 독립 사진 비교는 준비됐으나 실행 차단

카르카손·사그라다·티켓 투 라이드의 서로 다른 기존 연구 원본 3장에 대해 선택 ROI의 부분 기준 **62물체**, 별도 가시 묶음 **8개**를 출력 전에 고정했다. 사람 인증 GT는 아니며 high/medium 불확실성을 분리한다. 동일 원본 crop을 독립 사진으로 세지 않는다. [선정](selection.json), [평가 계약](evaluation-preflight.json), [동결 요청](preflight.json).

A 전체-low / B 동일 전체-medium / C 동일 원본의 물리영역 crop-low만 비교한다. 9개 body를 다시 대조하여 A/B는 effort, A/C는 이미지 외 동일함을 확인했다. GT는 모델 요청에 넣지 않는다. 최대9회·peak2·retry0, 사전 요금 환산 예약 **$1.8432 / 예산 $2**이며 실제 청구 상한을 보장하지 않는다. 승인된 원문 사용 외 추가 전송은 없다. [사전 확인](pending-verification.json), [채점 스크립트](score-evaluation.mts).

**자동 승인 검토가 외부 사진 전송·유료 사용·기존 키 읽기에 대한 직접 승인을 확인하지 못해 실행을 거절했다. 프로세스 시작 및 새 모델 호출은 0이다.** 직접 사용자 승인 질문을 남겼으며 우회하거나 다른 실행자로 중복 발행하지 않는다. [차단 기록](approval-block.json).

후속 결정은 결과가 확보된 뒤 한다. effort만 바꾼 B가 실제로 더 잘 읽는지, C가 단순 누락·값 오독을 줄이는지, 새 중복/오연결과 시간·요금이 늘어나는지 각각 판단한다. 지금 medium 기본 전환이나 항상 whole+crop 강제를 권고하지 않는다. 결합 보완은 인계하지만 전체 품질 과제는 이 비교 및 필요한 후속 판단이 남아 있다.
