# Terra 품질 반복 — 첫 구현 slice

제품 후보를 동결하고 Astra 독립 검토에 전달했습니다. 새 모델 호출은 **0**입니다.

- 퇴역한 묶음은 원관측에 보존하되 활성 편집 경쟁자에서 제외했습니다.
- 등록된 같은 원본에서 경계가 온전하고 상호 유일한 묶음 표면만 연결합니다. 숨은 내용물 동일성·총수량은 확정하지 않습니다.
- 서로 다른 종류는 합치지 않습니다. 완전한 single footprint의 좁은 충돌만 원 anchor와 미해결 관측으로 남깁니다. 판 위 말·인접물·같은 사진의 다른 층은 공존합니다.
- 모델·프롬프트·팩·사용자 필수 확인 동작은 변경하지 않았습니다.

고정 개발사진 10개의 부분 AI 참조에서 개별 편집물 대응은 **103→104/147**입니다. Carcassonne ROI에 이미 존재한 타일 1개가 결합 후 보류되던 것을 회수했습니다. 나머지 9개의 개별 대응 수는 같습니다. Quacks 중복은 **미해결**이며 기준을 사진에 맞춰 낮추지 않았습니다. raw 341건은 전부 보존했습니다. 새 독립사진 일반화·전체사진 정확도 결과가 아닙니다.

검증: 직접 집중 42/42, 합성 HTTP 2/2, 저장된 20응답의 실제 loopback 저장·재개 10/10, 동일 요청 재전달 추가 호출 0, 기존 18응답 값 749/749 보존, typecheck/build exit0. 전체 suite는 감독 통합 검사와 분리합니다. 브라우저는 이전 전역 Chrome 조작 금지 지시를 유지해 미실행입니다.

`baseline.json`과 private preimage가 실제 변경 전 소스를 보존합니다. `before-scores.json`/`after-scores.json`, `before-http-replay.json`/`after-http-replay.json`, `comparison.json`은 전후 근거입니다. `source-freeze.json`에 5파일 pre/post SHA와 고정 기하 기준, `product.delta.patch`에 이번 delta를 기록했습니다. 과거 GT·응답·점수는 덮어쓰지 않았습니다.

다음 단계는 Astra 독립 검토 후 필요한 최소 교정입니다. 신규 3사진×3조건(최대9회) 실험은 감독 승인 후 Astra가 실행합니다. 구현 담당의 중복 모델 호출은 0을 유지하며, 결과와 독립 검토를 받은 뒤 필요한 다음 delta를 분리합니다.

## 별도 delta2

독립 경계 검토 후 `delta2-baseline.json`에 첫 동결 소스의 preimage를 추가 보존했습니다. `delta2.patch`는 첫 동결 이후의 4파일 변경이며 이전 patch를 덮어쓰지 않습니다. 최신 소스는 `source-freeze-delta2.json`의 postSHA로 고정합니다.

- 이미 같은 표면으로 증명된 부모 군집을 복수 부모로 세지 않고 전 부모 관측의 퇴역·자식 출처 관계를 보존합니다.
- 과거 부분 상세화 관계를 같은 source/definition/area/owner/epoch에서 유지하여 후속 전체사진이 부모 묶음을 다시 편집 수량에 더하지 않게 했습니다. 다른 영역·인접 그룹을 단순히 자식을 포함한다는 이유로 지우지 않습니다.
- 두 관측의 가독 수량이 다를 때 원 anchor/user 수량을 유지하고 선택적 더보기에 차이만 표시합니다. null은 0이나 관측된 불일치로 바꾸지 않습니다.

최신 검증: 집중46/46, loopback2/2, 고정20응답 저장·재개10/10, typecheck를 포함한 build exit0. Astra 합성 경계 스크립트를 별도 복사 재생한 `delta2-boundaries.json`에서 세 문제 모두 재현되지 않았습니다. 이것은 Astra의 최종 독립 승인과 별개인 구현자 재검증입니다. 기존 개발사진 결과는 104/147과 raw341 유지이며 새 사진 일반화·무누락 보장을 뜻하지 않습니다. 신규 독립9요청은 Astra 소유, 구현자 호출0입니다.

## 별도 delta3 — 최신 소스

Astra의 최종 메타 범위 검토에서, 부모 A의 재등장과 무관한 부모 B의 자식까지 관련 항목으로 표시되던 문제를 독립 재현했습니다. `delta3.patch`는 실제 대응한 부모의 retirement만 관련 자식 계산에 사용하도록 제품1파일+회귀1파일을 수정합니다. 값/수량/사진/관측은 변경하지 않습니다.

최신 소스 기준은 `source-freeze-delta3.json`의 5개 postSHA입니다. 집중47/47·합성 HTTP2/2·typecheck/build exit0, 10게임 재생은104/147/raw341유지입니다. 저장20응답의10게임HTTP10/10은 delta2에서 확인했고, delta3는 메타 필터 회귀와 실제 loopback 저장회귀2/2로 확인했습니다. `delta3-boundaries.json`의 네 문제 비재현은 구현자 재검증이며 Astra 최종 독립 결과와 분리합니다. 새로운 모델 호출은 여전히0입니다.

최종: Astra가 5소스 해시·합성4경계·저장20응답104/147/raw341을 독립 재확인했으며 좁은 결합 slice의 추가 필수수정 발견0으로 제품 소유권을 감독에게 반환합니다. 근거는 상위 `independent-final-review.{md,json}`입니다. 새 사진9회는 실행 전 승인 검토 차단으로 미실행이며 이 제품 패키지의 완료와 분리합니다.
