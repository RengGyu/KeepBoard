# 20게임 낮은 회수율 원인 재분석

2026-10-29. 기존 원사진·요청·원응답·채점만 재분석했다. 새 API 호출·제품 변경·동결 기준 수정 0.

## 확인된 핵심

값을 다르게 읽는 것보다 **개별 실물 미회수/묶음 처리**가 점수를 크게 낮췄다. 고정 평가에서 실물 미회수 175개 중 92개는 묶음 대응으로 분류됐고, 나머지 83개는 개별 대응이 없었다. 단 ‘묶음’은 기존 채점자의 분류이며 null 수량만으로 물체가 여러 개라고 증명할 수는 없다.

앞·뒷면을 제외한 요청 값 636개는 다음과 같다.

| 상태 | 개수 |
|---|---:|
| 물체를 개별로 못 찾아 값 회수도 실패 처리 | 285 |
| 개별로 찾았고 기준값에 대응 | 317 |
| 개별로 찾았으나 값은 unknown/누락 | 21 |
| 개별로 찾았으나 기준 오류·등가 판정 불확실 | 11 |
| 개별로 찾았으나 값 불일치 | 2 |
| 합계 | 636 |

값 미회수 319개 중 285개(89.3%)가 개별 물체 미회수에 따라 발생했다. 개별로 찾아낸 물체만 조건부로 보면 317/351=90.3%다. **찾기 쉬운 물체만 남기는 조건부 수치이므로 전체 성능을 대체하지 않는다.** 49.8%는 읽어낸 값 중 오독 비율의 반대가 아니라, 누락까지 포함한 회수율이다. 두 불일치는 SCOUT의 6→9와 Kingdomino 성의 blue and yellow→blue 부분 색 표현이다. 전체 이미지의 오독이 두 건뿐이라는 뜻은 아니다.

## 실패 경로

### 1. 개별 분리보다 집단을 반환

티켓 투 라이드의 기차 여러 개를 노선/색별 묶음으로 반환했고, 캐스캐디아 전경 타일은 큰 박스 한 개(quantity16)였다. 이런 결과는 종류·색이 있어도 하나씩 정확한 위치로 복원할 수 없기 때문에 개별 회수에 실패했다. 기존 채점상 묶음 관련은 TTR65·Cascadia21·Splendor6=92개다.

현재 프롬프트는 ‘한 행은 한 물체’와 동시에 ‘분리 불가능한 그룹은 수량 또는 null’도 허용한다. 평가의 개별 분리 성공과 요청에서 허용한 부분 관측은 같은 기준이 아니다. 모델 지시 이행 실패와 허용된 부분 표현을 구분해야 한다.

### 2. 평가가 부분 정보의 효용을 덜 반영

스플렌더 공급 칩은 원응답에서 white/green/blue/red/black/gold를 읽었지만, 수량 null인 칩 더미 결과를 개별 실물에 연결하지 않아 물체0/6·값0/6이었다. 원사진에는 최상단 칩 색이 보이며 박스도 해당 위치에 있다. 이는 ‘칩을 전혀 보지 못함’과 다르다. 특히 null 수량 자체가 그룹이라는 확정 증거는 아니므로 해당 채점은 추가 판정 여지가 있다. 원점수는 바꾸지 않고 이 감사에 남긴다.

사용자가 일부 자동 배치 미완성을 허용한 현재 목표에서는 개별 배치 가능 여부와 그룹/영역 수준에서 유용한 읽힌 정보를 별도로 볼 필요가 있다. 그룹 색을 임의로 모든 개별 칩의 확정값으로 복제하자는 뜻은 아니다.

### 3. 빈 원응답과 실제 세부값 누락도 존재

블로커스·보난자·스플렌더 듀얼은 provider-native items=[]였다. 사전 기준 대상 합계31개이며 디코더가 지운 것이 아니다. 원사진에는 허용 종류의 실물이 보인다. 왜 모델이 빈 응답을 골랐는지 내부 원인은 **미확정**이다. 영역 해석·사진 내용·요청 이행·모델 변동을 분리한 추가 비교가 없으므로 순수 시각 능력 탓으로 확정할 수 없다.

사그라다는 전경 주사위20개와 틀을 찾아 색은 반환했지만, 사전 기준에서 읽을 수 있다고 본 눈값19개를 원응답부터 unreadable로 남겼다. 전반적 오독이 아니라 구체 세부값 미판독이다. 작은 투명 주사위/반사/원본 한 장 조건이 영향을 줄 가능성은 있으나, 근접사진과 같은 조건으로 비교하지 않아 인과는 미확정이다.

### 4. 지정 영역과 입력의 구체성이 다름

이번 시험은 원본 한 장씩이었다. 전체+근접4장 스캔 시험이 아니다. 모델에는 ecosystem/town 같은 영역 id와 허용 종류를 보냈고, 평가자가 고른 전경 개인판의 구체 ROI 좌표는 보내지 않았다. 여러 개인판이 있는 사진에서 다른 판의 실제 실물을 반환해도 모두 환각이나 영역 위반으로 단정할 수 없다. 전체 장면 물체를 모두 개별화하는 부담과 대상 판의 모호함이 함께 들어간 시험이다.

### 5. 기준 오류는 일부 있으나 큰 물체 누락을 모두 설명하지 않음

칼리코 명칭·코드네임 단어·스카우트 숫자·자이푸르 종류·패치워크 모양의 값11개가 기준/판정 불확실로 분리됐다. 킹도미노의 도미노 한 경계도 의심 상태다. 원래 기준을 조용히 고치거나 새 점수를 정답률로 내지 않았다. 이런 이의가 있지만 기차·타일의 개별 분리 실패와 빈 응답이 사라지는 것은 아니다.

## 현재 처리 코드의 손실 여부

기본20응답의 parsed→제품 decoded를 다시 검사했다. 원응답287행의 종류·수량과 실제 관측값668필드가 모두 유지됐다. 이 범위의 값 소실0. **이번 점수의 주된 손실은 모델 원출력과 개별 대응 판정 단계**다. 그림판·저장·배포 종단 전체를 이 검사로 다시 검증한 것은 아니다.
