# 카탄 외 20게임 판독 · 데이터팩 보강 시험

2026-10-29. 현재 Gemini 3.8 Flash / LOW / HIGH / 최대 출력 32768. 제품 수정·배포 없이 현재 요청 생성기와 디코더를 직접 사용했다. 원본 20회 + 데이터 부록 4회, 재시도 0.

**사전 AI 시각 기준 대비 개별 실물 회수는 201/376 (53.5%)였다. 앞·뒷면 구분을 제외한 읽을 수 있는 요청 속성 회수는 317/636 (49.8%)였다.** 전체 사진·게임 정답률, 출력 정밀도 또는 최종 배치 성공률은 아니다.

기준은 기존 Sol/high 두 세션이 새 응답 열람 전에 사진 10장씩 직접 보고 동결했다. Astra/Ultra는 별도로 부록을 정답·사진·출력 열람 전에 동결했다. 사람의 전량 정답집이 없고 무작위 표본도 아니다. 겹침·작은 글씨·가림 때문에 일부 게임은 명시한 영역의 확인 가능한 실물만 평가한다. 카드 더미는 식별 가능한 노출 앞면만 대상으로 하며, 뒤에 숨은 장수를 포함하지 않는다.

게임마다 같은 비중을 주는 단순 평균은 개별 회수 61.0%, 값 회수 55.3%다. 본문 합산 비율은 물체가 많은 게임의 비중이 크므로 함께 구분한다.

## 기준표 자체의 이의

동결 후 대조에서 칼리코 토큰 명칭, 코드네임 작은 글씨, 킹도미노 실물 경계, 스카우트 숫자, 자이푸르 카드 종류 등에 오류·불확실 가능성이 발견됐다. 카르카손에는 추가로 보이는 미플이 사전 부분 기준에 없었다. 원기준을 바꾸지 않고 점수 파일의 referenceIssues에 남겼다. 이 위치의 불일치는 확정된 모델 오류가 아니다. 위 수치는 **고정한 AI 참조와의 대응률**이며, 몇 자리 소수까지 실제 정확도를 인증하는 수치가 아니다. 미판정 예측을 전부 오검출로 세지도 않았다.

## 시간·토큰

20회 공급자 응답: 평균 16.35초 / 중앙 13.38초 / 최소 3.25초 / 최대 60.95초. 최대 5동시, 전체 배치 88.34초. HTTP200·STOP·제품 디코딩 20/20. 빈 응답도 성공 판독으로 간주하지 않고 회수 실패에 포함했다.

입력 33,665, 출력 40,197, 공급자 total 76,722토큰. thoughts는 2건에서만 합계 2,860로 보고됐고 나머지는 미보고다. 미보고를 사고 사용량 0으로 단정하지 않는다. 업로드·스캔 촬영·화면 반영·저장 시간과 실제 청구액은 이 시험에서 측정하지 않았다.

## 게임 데이터팩 부록 4쌍

사진·설정·스키마·기본 프롬프트는 같고, 공식 근거가 있는 짧은 게임 설명 부록만 덧붙였다. 실제 제품 팩이나 코드는 바꾸지 않았다. 추가 입력 합계 879토큰(건당 약 220).

| 게임 | 개별 실물 기본→부록 | 요청 속성 기본→부록² |
|---|---:|---:|
| 캐스캐디아 | 17/39 → 18/39 | 34/78 → 36/78 |
| 킹도미노 | 6/7 → 6/7 | 25/31 → 25/31 |
| 도미니언 | 13/13 → 13/13 | 39/39 → 39/39 |
| 타이니 타운즈 | 1/1 → 1/1 | 1/1 → 1/1 |

² 이 표는 비교 원자료의 요청 속성 전체(face 포함) 기준이며, 본문 20게임의 face 제외 값 회수율과 분모가 다르다.

4게임 합계 개별 회수 37/60→38/60, 요청 속성 99/149→101/149. 늘어난 1개는 캐스캐디아 동물이며 동시에 기존 서식지 큰 묶음이 사라졌다. 개별 점수만으로 전체 내용 보존이 개선됐다고 볼 수 없다. 나머지 3게임은 같은 점수다. 양 조건 각 1회이며 호출 시점·출력량·동시 실행 양상이 달라 데이터나 속도의 인과 효과는 확정하지 않는다. 최종 자동 배치의 개선과 사용자 수정 시간은 시험하지 않았다.

현재 근거로는 데이터팩의 전면 증량보다 **게임·영역에 필요한 실물 구분과 어휘를 작게 추가하는 후보**가 적절하다. 확인된 색→재료명, 확인된 두 반쪽의 연결 같은 고정 매핑·계산은 코드 후보지만, 숨은 값·재고·미관측 배치는 만들지 않는다. 이번 시험에서 코드 매핑의 실효 성능까지 검증한 것은 아니다. 상세 연구 최종 해석은 [Astra 결과](astra/experiment-result.md), [공식 근거와 설계](astra/README.md)에 분리했다.
