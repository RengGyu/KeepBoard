# 고정 아트 계약

카탄과 카르카손의 기존 도형·CSS에서 추출했다. 원본 아트는 수정하거나 새 개별 사본으로 만들지 않는다. 자세한 값은 [style-contract.json](style-contract.json)에 고정한다.

- 120×120 좌표계, 크림 `#fff9e9`, 종이 `#eee1c5`, 숲 윤곽 `#33483c`. 주 윤곽 1.7, 보조 1.4, 재료 결 1.0. 둥근 선 끝과 이음새를 유지한다.
- 목재는 전면·작은 옆면·크림 하이라이트로 표현한다. 색을 바꿔도 외곽·재료 결은 같다. 밝은 부분은 크림 반투명, 어두운 옆면은 숲색 반투명으로 기존 명도 관계를 따른다.
- 지형은 낮은 채도의 평면 색층과 재료 실루엣으로 그린다. 그라디언트나 사실적인 그림자는 추가하지 않는다.
- 소유색은 기존 빨강·파랑·초록·금색이다. 카드 계열, 동물 종류, 부족 종류, 알 장식색 같은 의미색과 별개다. 소유색을 지원하는 에셋만 `--owner`를 사용한다.
- 공통 큐브·말·토큰·주사위·자원·카드 틀은 공통 ID를 참조한다. 카드 틀과 구분용 의미 도형을 합성하며, 틀만으로 모든 카드 제작을 완료했다고 세지 않는다.
- 숫자·수량은 장면 데이터의 오버레이다. 모름은 `?`, 실제 0은 `0`이다. 더미 층·자원 묶음·카드 무늬의 개수는 실물 수량이 아니다.
- 24/32/48/64px를 실제 갤러리에 나란히 렌더한다. 단순 말은 32px, 지형·카드 세부는 48px, 복잡한 보드 구역은 64px 이상을 권장한다. 작은 크기의 실루엣 확인을 인식 정확도 검증으로 확대하지 않는다.
- 미확인 명세는 점선과 물음표로 남긴다. 그림의 예시 배치·형태는 실물 타일 ID, 연결 관계, 공식 인쇄판 지도나 합법 배치를 뜻하지 않는다.

시각 방향: 따뜻한 종이 위에 놓인, 밝은 목재와 절제된 재료색의 작은 실물 조각.

갤러리 구성: 대표 부품 → 크기·소유색 비교 → 120종 검색·게임별 구성물 → 출처·미확인 범위. 검색 결과의 부드러운 전환과 항목 확대만 사용하며 그림을 가리는 장식은 넣지 않는다.
