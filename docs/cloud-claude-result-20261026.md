## 2. Gemini 3.8 화면 연결

- 선택기·작업 전송(`reader: gemini-game-observation-v1`, 현재 정의 SHA·영역·사진 한 장)은 이미 코드에 있었고 테스트로 확인되어 있었음. 이번에 추가: 판독기 영수증의 **가려짐/읽기 어려움/수량 모름**을 후보 카드("확인 필요 n"), 후보 확인 편집기(첫 공백 실물부터 열림, 해당 칸 강조), 실물 연결 대화상자의 정정 양식(범용 게임 상세 필드 포함), 카탄 후보 확인에 표시. 서버가 보고한 모델 식별자를 "읽기 설정"에 표시. 조립된 실물이 구성물 ID를 표시 이름으로 쓰던 문제 수정.
- **검증 범위**: 로컬 합성(fixture) Gemini 판독기로 아줄·카탄에서 선택 → 읽기 → 후보 → 가려진 값 입력 → 연결/적용 → 저장 → 다시 열기를 브라우저에서 확인. **실제 Gemini API 호출은 0회**(키 없음). `docs/gemini-game-integration/product-smoke.mts`는 실행하지 않음.

## 3. 게임팩 규칙 우선 개정

- 이 세션에서는 출판사 사이트에 접근 불가(WebFetch DNS 실패, 프록시 403). 저장소에 보관된 공식 규칙 텍스트가 있는 게임만 대조: **9종 개정**(Crew Deep Sea, Agricola, Anachrony, Arkham Horror 3, Barrage, Istanbul, SETI, Star Wars: Rebellion, Voidfall), **10종 일치 확인·변경 없음**, **2종 부분 텍스트**(Marvel Champions, Monopoly), **91종 미검토**. 전체 규칙서 검증 완료로 표시한 게임은 0. 상세: `docs/gamepack-revision-20261026/cloud/`.
- 기존 필드의 범위·공개 여부는 바꾸지 않고, 새로 분리한 공개/본인/숨김 부분은 새 영역·필드로 추가. 이전 기록(Arkham LCG·Pandemic Legacy 포함)은 자동 이동하지 않음.

## 4. 생성 데이터 동기화

- `docs/gamepack-revision-20261026/revision.json`: 동결 인벤토리(개정 전 생성물에서 추출)와 현재 정본으로 **계산된** 개정 원장. 게임별 이전/새 다이제스트, 추가된 필드·구성물·영역 ID, 근거 영수증. 과거 고정 수치(필드 1360·구성물 437·영역 522)는 기준값으로 계속 검사하고, 현재 기대값은 원장에서 계산(필드 1373·구성물 440·영역 534).
- 기존 동결 검사는 삭제하지 않음. 바뀐 소스는 "동결 해시 그대로" 또는 "원장 행의 정확한 대체"만 허용.
- 개정되지 않은 게임은 캡처 프로필·사진 정의 계약 행·사진 정의가 과거 기록과 바이트 단위로 같음(테스트). 이전에 승인된 본인 사진 권한은 같은 필드·같은 공개 범위일 때만 유지.
- 새로 분리한 구성물은 공용 '미확인' 그림만 사용(실물 앞면을 그리지 않음).
- 개정으로 대체된 팩 버전은 `gamepacks/generated/retired-packs.json`에 보존해, 팩이 내장되지 않은 오래된 저장본도 열림.
- 재생성: `tools/game-runtime/revise-all.sh`. 사진 정의 계약 SHA는 검토 후 `generate-photo-definitions.mts`의 `APPROVED_CONTRACT`에서 갱신.
