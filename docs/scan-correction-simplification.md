# 사진과 그림 정정 중심으로 단순화

2026-10-21. 사용자 위임에 따라 설계와 구현을 함께 진행한다.

- 첫 화면은 사진 추가, 그림/원본 전환, 부품 정정이다. 질문 진행률과 보관 탭을 없앤다.
- 선택은 단일 편집과 여러 개 선택으로 구분한다. 여러 개는 공통 소유색 변경과 삭제만 제공하고 한 번에 되돌린다.
- 추가는 종류 → 필요한 속성 → 자리 선택 순서다. 기존 부품 목록과 분리한다.
- 위치 정정은 기존 교환/수량 분할을 재사용한다. 규칙 경고·원본 승인 질문을 사용자에게 요구하지 않는다.
- 그림 정정은 저장·화면 전환 전에 먼저 반영한다. 누구 차례인지와 선택 메모만 곁들이고 모르는 내용은 비워둔다.
- 기존 질문·보관·카드 이력·원본·저장본의 계약은 삭제하지 않는다. JSON과 내부 진단을 일반 화면에서 제거한다.
- 카드 수는 소유자 화면에서 필요할 때 펼쳐 고친다. 공용 화면은 공개 합계만 표시한다.
- 저장은 현재 상태 그대로 가능하다. 이어하기는 기존 저장본/턴을 유지하며 완벽 복원을 약속하지 않는다.

검증: 합성 세션만 사용하며 실제 AI·카메라·개인 저장소는 호출하지 않는다.

## 반영 결과

- `src/SessionWorkspace.tsx`: 그림 고치기/저장/이어하기의 세 화면. 기존 질문·보관 진행률·복원 체크리스트를 제거하고 차례/단계/선택 메모로 대체했다. 저장·소유자 전환·내 보드 이동 전에 그림/카드/메모 초안을 반영한다. 기존 `commit(allowIncomplete: true)` 계약을 사용한다.
- `src/SceneEditor.tsx`, `shared/sceneEditing.ts`: 단일 선택과 다중 선택을 분리했다. 공통 소유색/삭제를 한 번의 이력으로 반영하며 삭제된 부품의 연결만 해제한다. 추가는 종류별 설정 후 자리 선택/확정이며 위치 나중에 기록도 가능하다. 이동/교환/묶음 수량 분할은 기존 함수의 정정 경로를 재사용한다.
- `src/SceneWorkspace.tsx`: 원본/그림의 같은 부품 선택과 새 사진 결과/기존 그림 전환을 유지했다. 정정 중 결과 전환으로 초안이 사라지지 않도록 반영 후 전환한다.
- `src/CatanOverview.tsx`, `src/Fields.tsx`: 개인 카드/남은 말은 소유자 화면에서 펼친다. 카드 초안도 전체 저장·화면 이동에 포함한다. 공용 합계와 항구 교역 참고는 선택적으로 펼치며 상세 교역 기록은 유지한다.
- `src/App.tsx`, `src/Dialogs.tsx`: 일반 사용자용 JSON 가져오기/내보내기와 내부 게임팩 진단·생성 UI를 제거했다. 내부 API와 기존 데이터는 유지한다.
- `src/correction-workspace.css`, `README.md`: 현재 밝은 디자인/부품 아트를 유지하며 작은 화면과 새 제품 목표·흐름을 반영했다. 서버/인식 프롬프트/저장 스키마/게임팩은 수정하지 않았다.
