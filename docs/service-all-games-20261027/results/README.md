## 서비스 응답 처리에서 확인한 문제

- 에이지 오브 이노베이션·도미넌트 스피시즈: 모름을 JSON null 대신 문자열 `"null"`로 반환해 현재 디코더가 거절했다.
- 마블 챔피언스: 정수 단계에 문자열 `"1"`을 반환해 현재 값 검증이 거절했다.
- 위 최초 실행 3건은 HTTP200 판독 응답은 받았지만 후보 생성에 실패했다. 원응답은 보존했고 보정·재요청하지 않았다.
- 최초 배치 실행기의 중단 조건에 HTTP402가 빠져 있어 거절 응답이 이어졌다. 감독이 원인을 확인해 실행 프로세스를 중단했다. 원래 실행기와 원응답을 보존했고 추가 실행 전 HTTP402 즉시 중단 조건을 보완했다.
- 추가 실행의 테라포밍 마스: 원응답의 cubes 항목에 terrain 전용 속성(face/printedName/tileType)이 붙어 현재 종류별 속성 검증이 거절했다. 재보정·재요청 없이 원응답을 보존했다.

이 검사는 제품의 현재 로컬 API 경로를 사용했다. 배포 사이트의 브라우저 화면, 스캔의 여러 프레임, 다른 판본·조명·게임 진행 상태는 이번 범위에서 시험하지 않았다.
