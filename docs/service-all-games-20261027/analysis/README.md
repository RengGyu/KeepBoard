# 불일치는 정정 가능한 차이부터 개별 상태가 사라지는 실패까지 나뉩니다

**현재 사진 표본에서 빈 결과는 13종, 판·묶음 또는 다른 대상만 읽어 주요 표본이 사라진 경우는 12종입니다. 둘을 모두 “전혀 인식 못함”으로 묶으면 안 됩니다.**

나머지에서는 일부 실물 누락·값 오독 18종, 필드 연결·사용자 입력 2종, 서비스 응답 처리 실패 4종이 확인됩니다. 표본 일치 62종과 사진 판단 보류·솔 참조 오류 8종은 따로 둡니다.

## 허용 여부를 정하는 기준

- **허용 가능:** 같은 실물·종류·중요 값이 보존되고, 색의 동의어·번역·근사 상자 차이만 있는 경우. 단, 상자가 다른 물체를 가리키거나 복원 위치가 바뀌면 허용할 차이가 아닙니다.
- **조건부 사용:** 일부 물체나 값은 맞지만 누락·오독이 있는 경우. 맞은 결과는 재사용하고 빠진 것만 정정할 수 있으나, 정정 없이 자동 복원해도 된다는 뜻은 아닙니다.
- **현재 빠른 저장에는 부족:** 빈 결과, 판·무리만 검출, 검사 대상 전부 미대응, 후보 생성 실패. 사용자가 대부분을 다시 입력해야 하거나 서비스가 입력을 받아들이지 못합니다.
- **판정 보류:** 사진 자체의 애매함과 잘못된 수동 참조. 모델 오류로 확정하거나 통과로 올리지 않습니다.

위 기준은 이번 검토의 권고입니다. 정정 시간·버튼 수와 사용자 허용률은 측정하지 않았습니다.

## 정확도 수치를 읽는 방법

이번 자료는 사진 전체의 완전한 정답 목록이 아닙니다. 따라서 정확도·재현율 몇 %라고 쓰지 않습니다. 아래 `확인된 실물/표본`은 기존 사진 재검토로 대응이 확인된 일부 물체 수이며, 값까지 모두 맞다는 뜻도 아닙니다. 자동 IoU·문자열 비교 수치는 원자료에 남기되 사람의 재검토 비율로 바꾸지 않았습니다.

예: 러브레터는 검사 카드 2장 중 1장을 누락했습니다. 그랜드 오스트리아 호텔은 주사위 3개를 찾았지만 눈값은 3개 중 2개를 다르게 읽었습니다. 테라포밍 마스는 표본 큐브를 읽었어도 잘못된 종류별 속성 때문에 서비스가 전체 후보를 만들지 못했습니다.
