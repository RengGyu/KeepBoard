# 57종 사진 판독 차이: 실용 재평가

**결론: 필수 수정 18종, 수동 정정으로 허용 27종, 평가자료 수정 대상 6종, 근거 부족 6종.**

57장을 직접 열고 원응답·참조 57쌍과 현재 정정 코드를 확인했다. 우선 고칠 것은 **읽은 관측까지 통째로 잃는 처리 실패 4종**이다. 나머지 필수 보완 14종은 빈 결과/정적 판 위주 출력으로 현재 기물 상태의 출발점이 부족했다. 사진을 보관하고 실물을 복원하는 기존 경로를 막자는 결론은 아니다.

수동 허용 27종은 각 행의 조건을 전제로 한다. 원본을 위치·방향의 기준으로 쓰고, 필요한 기물/수량/값만 추가하거나 고친다. 모든 타일·공급물·겹친 카드를 낱개로 전사할 필요는 없다. **정정이 쉽다거나 몇 번/몇 초 걸린다는 측정은 하지 않았다.**

## 사실과 판단

- **VERIFIED:** 57개 원응답 JSON·원참조를 읽었고 사진 57장을 직접 열었다. 사진/참조/원응답 해시 171개가 기존 기록과 일치했다. 원결과 SHA는 `51a348efa740aa24c067bfb38c1ef7f60bb56e3f7b869a7f7926fb0872e21f9b`. 현재 입력 파일 해시는 [JSON](astra-practical-review.json)의 `inputs`에 기록했다.
- **VERIFIED:** 후보 없음 안내는 사실대로 나오며, 원본 보존·수동 추가·종류/수량/상세속성/위치 메모 수정·명시 적용·저장 경로가 소스에 있다. 실제 UI 조작이나 새 API/모델 실행은 하지 않았다.

- **RECOMMENDATION:** 아래 주판정과 조치. 이 57종은 과거 차이가 있었던 선택 집단이며 전체 119/120게임 정확도 또는 서비스 출시 차단 목록이 아니다.

## 먼저 고칠 범위

1. **P0 — 처리 손실 4종:** 혁신의 시대·도미넌트 스피시즈의 문자열 `null`, 마블 챔피언스의 숫자 문자열, 테라포밍 마스의 구성물별 허용 속성 혼입. [`decodeGeminiGameObservation`](../../../server/ai/geminiGameReader.ts:22)의 전체 예외 처리로 유효 관측도 정정 후보에 도달하지 못했다. 잘못된 속성을 미확인으로 분리하고 다른 유효 관측을 보존하는 작은 수정이 우선이다. 무조건 타입을 강제 변환하거나 범위 검사를 없애자는 뜻은 아니다.
2. **P1 — 넓은 관측 누락 14종:** 아래 표의 P1 게임에 한해 실제 영역/대상 종류를 맞춰 보완한다. 전게임 새 인식 엔진이나 완전 자동복원은 요구하지 않는다. 사진 기준 복원은 유지하되, 다수의 움직이는 기물이 보이는데 판 한 건/빈 결과뿐인 것을 한두 항목 정정으로 축소하지 않는다.
3. **평가자료 6종:** 원참조 오류 4종은 인식 오독에서 제외한다. 아발론은 금지된 역할 필드 기대를, 익스페디션은 이미 읽은 이름의 필드 배정 기대를 조정한다. 기존 GT/원결과는 이 작업에서 수정하지 않았다.

공통 코드: [후보 없음 안내](../../../src/analysisJobMessage.ts:2), [후보 확인·적용](../../../src/GameEssentials.tsx:36), [구성물 추가·정정](../../../src/GameEssentials.tsx:91), [상세값 수정](../../../src/readouts/GameDetailFields.tsx:9), [저장](../../../src/SessionWorkspace.tsx:128). 자동 묶음 분할 UI는 확인되지 않았고, 필요한 경우 추가·삭제·수량/위치 메모를 사용하는 조건이다.

## 집계 해석

기존 **50종 확정 / 3종 범위 / 4종 참조 제외**를 그대로 유지했다. 확정 50종은 152표본 중 개별 미확보 95(누락·대응 미확인 72 + 묶음 23), 범위 3종은 10표본 중 2~10, 유효 합계 53종 162표본 중 97~105다. 참조 제외 4종의 12표본은 분모가 아니다.

주판정의 평가자료 수정 **6종**과 원참조 제외 **4종**은 다른 축이다. 아발론·익스페디션은 수치표에서 여전히 exact/미확보 0이다. 빈 응답 13종, 처리 실패 4종의 13표본, 숫자 오독 2개는 겹칠 수 있으므로 합산하지 않는다. 이 숫자는 사진 전체 누락률이 아니다.

## 남은 한계·인계

실사진 1장/게임, 사전 표본 1~4개뿐이다. 새 모델 호출·제품 테스트·정정 UI 조작·클릭/시간 측정은 0회다. 수동 허용은 전체 판의 누락이 표본 수만큼이라는 주장이 아니며, 사진 밖 정보나 가림 아래 내용은 미확인으로 남긴다. 근거 부족 6종은 해당 자료/대응만 보완하면 되고 다른 게임의 테스트를 막을 이유는 없다.

제품·원GT·원결과·사진은 변경하지 않았다. 작성물은 이 문서와 `astra-practical-review.json` 두 개다. 검토 소유권을 반환한다.
