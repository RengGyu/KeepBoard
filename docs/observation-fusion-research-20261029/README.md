# KeepBoard 관측 결합 연구 — 2026-10-29

**권고: 같은 원본의 관측은 ‘물체 대응 → 묶음 상세화 → 속성 선택’을 분리해 결합한다.** 서로 겹친다는 이유로 개별 물체를 모두 막지 않는다. 전체사진은 최초 대표일 뿐, 그 AI 값이 영구 정답은 아니다. 숫자·선택형 속성은 충분히 대응된 부분사진을 임시 우선할 수 있지만 충돌 원문과 수동값을 보존한다. 다른 시점 사진의 자동 동일물체 판정은 이번 근거로 승인하지 않는다.

제품·팩·프롬프트·모델 변경 **0**, 추가 API **0**. 현재 제품 함수를 읽고 저장 응답을 다시 실행했다. 연구 코드·보고서만 이 폴더에 작성했다. 입력 목록과 SHA는 [inputs.json](inputs.json), 구현 가능한 계약은 [design.md](design.md), 실행 결과는 [replay-results.json](replay-results.json), 재현 코드는 [replay.mts](replay.mts)에 있다.

## 실제 응답 재생 결과

분모는 이전에 동결한 **AI 부분 참조표**다. 사람이 인증한 전체 실물 정답이나 전게임 정확도가 아니다. 평가 대응은 기존과 같은 종류·quantity1·최대합 IoU 일대일 배정 및 IoU≥0.25를 사용했다. **이 평가 임계값·GT·정답 수량은 결합 함수에 입력하지 않았다.** 실제 결합은 아래 design의 출처 경계와 일대일 공간 대응을 사용한다.

| 고정 부분영역 | 현재 결합 | 구조만 수정 | 권고 구조+속성 선택 | 남은 한계 |
|---|---:|---:|---:|---|
| Cascadia 개별 물체 대응 | 18/39 | 39/39 | 39/39 | 타일·동물의 모든 속성 정답을 뜻하지 않음 |
| Sagrada 창틀+주사위 대응 | 21/21 | 21/21 | 21/21 | 창틀1+주사위20; 칸 좌표 자동 배치는 별개 |
| Sagrada 읽을 수 있는 눈값 일치 | 1/19 | 1/19 | 15/19 | 4개 불일치 유지, 기존 맞은1개는 유지·14개 증가 |
| Splendor Duel 개별 토큰 대응 | 0/25 | 25/25 | 25/25 | 색 문자열22/25; yellow/gold 차이3개를 임의 정답 처리하지 않음 |

실제 생성한 편집용 `GenericRecord`는 Cascadia **30→50**, Sagrada **23→23**, Splendor Duel **0→25** 항목이며, 현재 `validateGenericRecord`를 통과했다. 합계 **53→98개 편집 항목**이다. 기준표 밖의 기존 항목13개도 남았으므로 98개가 모두 정답이라는 뜻은 아니다. 기존 anchor 항목 ID 50개는 유지하고, 큰 habitat 묶음1개는 원문을 남긴 **비가산 상세화 관계**로 옮겼다.

현재 UI의 `GameBoardRecord`는 이 기록을 미배치 구성물 버튼·상세 수정·저장 입력으로 소비한다. 따라서 raw 보관만 늘어난 결과가 아니다. 다만 **이번 연구에서 실제 브라우저 조작은 하지 않았다. 원사진 region을 게임판 placement로 변환하지도 않았다.** 자동 배치/재개 성공으로 확대하지 않는다.

관측136개는 전후 모두 보존된다. 편집 항목으로 연결된 raw 관측은 **90→135개**, 나머지1개는 상세화된 집합 관측이다. 알려진 편집 필드는 **112→206개**로 늘었다. 이는 중복을 합친 값 보유량이며 정확한 속성 수가 아니다. 부분 참조표에서 발견된 추가 중복 후보와 잘못된 교차 연결은 **각0**; 참조표 밖 전체 정밀도는 UNKNOWN이다.

속성 충돌은 사라진 것으로 위장하지 않았다. Cascadia 색 서술3건, Sagrada 눈/색 서술37건을 남겼다. 권고 정책은 이 중 Sagrada 숫자17건만 근거를 붙여 임시 재선택한다. ‘모든 필드에 crop 우선’을 적용한 비교안에서는 Sagrada `observedColor`의 문자열 일치가 **20/20→0/20**으로 떨어졌다(`yellow`와 `yellow translucent` 등). 이는 색 오인20개라는 증거는 아니지만, 자유서술까지 일괄 교체할 이유가 없음을 보여준다. 최종 정책은 문자형 충돌의 기존 표현을 유지하고 양쪽 원문을 남긴다. 정규형 `dieColor`는20/20을 유지했다.

## 문헌에서 가져온 것과 가져오지 않은 것

공식/저자 자료 확인일: **2026-10-29**. 논문 검출 벤치마크를 KeepBoard 성능으로 전환하지 않았다.

| 비교안 | 1차 근거 | KeepBoard 판단 |
|---|---|---|
| NMS/NMM로 박스를 억제·합침 | [SAHI 논문](https://arxiv.org/abs/2202.06934), [공식 결합 구현](https://obss.github.io/sahi/postprocess/combine/) | crop 박스를 원본 좌표로 되돌리는 원리는 유효. 그러나 NMS는 관측을 버리고, NMM의 전이 연결은 이웃·큰 묶음·개별 타일을 혼동할 수 있어 직접 채택하지 않음. 자유로운 VLM 속성 충돌도 해결하지 않음 |
| 점수 가중 박스 융합 | [WBF 논문](https://arxiv.org/abs/1910.13302), [저자 구현](https://github.com/ZFTurbo/Weighted-Boxes-Fusion) | 서로 같은 물체인 검출을 앙상블할 때 유용. 현 receipt에는 보정된 검출 확률이 없으며 숫자6과9를 평균낼 수 없음. 박스 평균이나 임의 confidence로 정답을 만들지 않음 |
| 출처가 제한된 일대일 대응 + 속성별 근거 | [SORT 논문](https://arxiv.org/abs/1602.00763), [저자 association 구현](https://raw.githubusercontent.com/abewley/sort/master/sort.py) | 검출과 identity association을 분리하고 미대응을 명시하는 원리만 채택. 정지 crop에 속도모델·Kalman·영상 추적기를 추가하지 않음. 겹침 후보가 유일한 경우만 연결하므로 이번 slice에는 Hungarian 의존성도 불필요 |

**선택은 세 번째다.** 게임별 새 엔진 없이 이미 있는 출처 변환·typed 값·편집 기록을 재사용한다. 부분사진이 더 맞는다는 일반 법칙은 이 문헌들이 증명하지 않는다. ‘좁은 촬영영역의 구조화 속성을 임시 우선’은 이번 재생으로 유용성이 관측된 **KeepBoard 가설**이며 다른 사진에서 악화할 수 있다.

## 검증·도입 경계

- 실제3사례: native→receipt 재해석, 기존 projector 일치, 역순 완료, 동일 결과 재전달, 원문 불변, scope/epoch/owner 거절, crop 실패 시 whole 보존, JSON 직렬화 왕복, 현재 typed record 검증을 실행했다.
- 별도 합성15검사: 이웃 동일 외형, 같은 물체 중복, 상보값·0, 충돌 필드만 분리, 잘못된 AI/수동값/수동unknown, 집합의 부분 상세화·수동 집합, 미등록 시점, 빈 응답·source/box 누락, 전이·경쟁 연결, 자유서술 차이. [실행 결과](replay-results.json)의 `synthetic`은 실사진 결과와 분리했다.
- 오프라인 결합 함수만 한 번 측정한 CPU 시간은 세 사례 모두 수ms 미만이었다. 네트워크·모델 시간 단축 실험이 아니며, 6개의 기존 유료 판독 시간·토큰은 그대로다. 추가 모델 없이 이미 읽힌 정보를 살리는 변경이다.
- 실제 HTTP 저장/재열기, late-result와 사용자 편집 경쟁, 수동 잠금 메타데이터의 제품 연결은 **미실행**이다. 기존 CAS를 유지하고 구현 후 이 좁은 경계를 검사한다. 광범위 재평가를 첫 구조 개선의 선행조건으로 만들지 않는다.
- 다른 시점에 대한 등록 품질, 독립 사진에서의 속성 재선택 성공률, 물리적 칸 복원, 사용자 정정 시간은 **UNKNOWN**. 바뀐 상태의 Cascadia 대체 사진은 입력에서 제외했다.

재현: 프로젝트 루트에서 `node --import tsx docs/observation-fusion-research-20261029/replay.mts`. 기존 연구 원본이 필요하다. 네트워크 fetch는 프로토타입에서 차단하며 원본·raw·GT를 보고서에 복제하지 않는다.
