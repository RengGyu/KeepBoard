# 원사진에 표시한 순차·병렬 판독 비교

[전체 사진: 순차 출력](sequential.jpg) · [전체 사진: 병렬 출력](parallel.jpg) · [분류 변경·누락 확대](changed-and-missed.jpg)

- 초록 상자: 모델이 도로로 반환한 항목. 하늘색: 항구로 반환한 표시. 노랑: 도시·정착지로 반환한 건물. 빨강: 알려진 누락.
- 색은 출력 종류를 뜻하며 정답 인증 표시가 아니다. 상자는 잘라낸 사진 좌표를 원사진 좌표로 선형 변환했다. 인식값이나 상자 위치를 정답에 맞춰 이동하지 않았다.

|위치|순차|병렬|판정|
|---|---|---|---|
|위쪽 흰 건물|도시|정착지|같은 실물·색 대응, 종류 불안정. 확정 정답 종류 미정|
|왼쪽 끝 빨간 건물|도시|정착지|같은 실물·색 대응, 사진 잘림으로 세부 종류 미정|
|아래쪽 흰 건물|정착지|도시|같은 실물·색 대응, 종류 불안정. 확정 정답 종류 미정|
|위쪽 파란 기물|미반환|미반환|참조는 건물 후보. 병렬 설명은 도둑으로 해석해 제외. 종류 혼동 및 누락|

도로 출력 6곳 중 5곳은 좁고 긴 실제 도로와 대응하며, 도둑 옆 빨간 실물 1곳은 도로/정착지 구분이 모호하다. 건물 출력 6곳은 실물 위치와 대응하나 세부 종류 정확도는 확정하지 않는다. 항구 5곳은 실제 인쇄 표시와 대응하나 자원 속성은 전부 null이다. 아래 두 3:1 비율은 사진에서 확인되며, 오른쪽 두 2:1은 저해상도로 확정하지 않는다.

이것은 AI의 원사진 대조이며 인간 인증 전량 정답이 아니다. 표적 선택한 4개 crop은 사진 전체의 모든 실물·항구를 보장하지 않는다. 이번 반복은 병렬의 속도뿐 아니라 모델 실행 변동도 포함한다. 병렬이라는 실행 방식이 종류 변화를 일으켰다고 인과 해석하지 않는다.
