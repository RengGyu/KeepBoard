# KeepBoard 게임별 개발 전달 패키지

2026-10-22 코드 스냅샷. ZIP을 웹챗 Pro에 첨부하고 `REQUEST-KO.md` 전체를 붙여 넣으세요. 첫 대상 gameId만 바꾸면 됩니다. 개인 사진은 포함하지 않았습니다. 필요하면 사용자가 권한 있는 사진을 나중에 웹챗에 직접 첨부하는 선택사항입니다.

## 첨부 목차

- `REQUEST-KO.md`: 그대로 복사할 개발 요청문
- `CURRENT-CONTRACT.md`: 현재 구현 사실과 확장 제안, 삽입 위치
- `GAME-TEMPLATE.md`: 게임별 관측/표시/저장 작업 양식
- `IMAGES.md`: 실제 SVG·매핑·재사용 규칙
- `VALIDATION.md`: 반환 구조와 검사 기준
- `data/games-120.json` 및 CSV: 전수 게임/판본/출처/필드·구성물 연결
- `data/targets-117.json` 및 CSV: 카탄·루미큐브·스플렌더를 제외한 작업 대상
- `snapshot/`: 허용 목록으로 복사한 현재 소스, 120 연구 JSON, 실행팩, 이미지와 테스트
- `DEPENDENCIES.md`: 실제 미첨부 상대 import 목록과 독립 실행 한계
- `examples/splendor-manual-synthetic.json`: 실제 현행 타입을 따르는 수동 합성 null/0 예시 (사진 판독 결과 아님)
- `MANIFEST.json`: 파일 크기·SHA256·실제 복사 목록

## VERIFIED 현재 범위

현재 120 실행 카탈로그가 있으며 카탄·루미큐브 2게임은 전용 기록 편집 경로, 나머지 118게임은 조건을 충족하는 공개/본인 구성물에 공통 AI 후보 경로가 있습니다. 스플렌더는 그 공통 경로 위에 `splendor-v1` 구조화 판독/표시/편집 계약이 추가되었습니다. 따라서 대상 117게임은 ‘아예 미지원’이 아니라 기존 공통 기록/그림/판독 위에 필요한 게임별 상세 양식을 추가 검토할 대상입니다. 각 게임의 모든 전용 기능 유무를 이 패키지가 전수 실행검증한 것은 아닙니다.

게임별 출처·판본·binding·component는 추출 데이터로 확인하세요. 아트 대표 변형 수는 실물 종류나 수량이 아닙니다. 연구 JSON의 confidence/gaps와 공식 확인 범위를 보존하세요. source SHA와 art mapping SHA가 다르면 재생성 완료로 고쳐 쓰지 말고 의미 변경 여부를 먼저 확인하세요.

## 사용 경계

이것은 참조 코드 부분집합이며 독립 실행 앱이 아닙니다. import 대상 일부와 실행 데이터·설정·전체 스타일·앱 진입부는 의도적으로 빠졌습니다. 웹챗이 반환한 패치는 실제 저장소에서 적용·검증해야 합니다. 테스트가 첨부돼 있어도 이 ZIP만 npm 설치/실행하면 통과한다고 주장하지 마세요. 비밀키, 실제 사용자 사진·세션·운영문서·백업은 없습니다.
