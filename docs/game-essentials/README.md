## 사실과 앱 권고의 구분

`*.essentials.rules`는 선택 판본의 공식 규칙에서 확인한 **기록에 필요한 특정 사실**만 가리킨다. 각 문서 제목/URL/판본/페이지 또는 절/열람일/로컬 해시는 evidence에 있다. 기존 게임 전체 `confidence`를 올리지 않았으며, 기존 gaps를 지우지 않았다. 한 필드의 존재가 공식 사실이어도 그 필드를 저장하는 JSON 표현·봉인 방법·보관 위치·참조 사진 방식은 KeepBoard의 설계다.

`essentials.storage-guidance`는 **RECOMMENDATION**이다. 공개 장면을 정리할 때 참조와 구역별 묶음을 남기고, 비밀 실물을 펼치지 않은 채 묶음 ID·소유자/허용 역할·봉인·위아래·보관 위치로 보존하는 절차다. 공식 출판사가 앱용 포장법을 정했다는 뜻이 아니다. 원래 순서가 의미 없는 풀/주머니에 새 게임상 순서를 부여하지 않는다.

공개 총수는 비공개 정체와 별개다. 공개 여부의 근거가 부족하면 공개 수량 필드를 무작정 만들지 않았다. 자이푸르는 공식 규칙이 보유 낙타 수를 알릴 의무가 없다고 명시하므로 시장/자발적 공개 부분과 개인 보유를 분리했다. 루미큐브·루트·티켓 투 라이드 등의 기존 검토표에 있는 ‘장수 공개’ 추정은 이번에 확인한 원문이 명시하지 않으면 UNCLEAR로 유지했다.

## 저장·재개 정책

- 기존 게임 ID/필드 ID/판본 객체/컴포넌트/원래 필드 공개범위와 타입을 유지했다. 스키마 변경 없음.
- 기존 `required_field_ids`·`must_ask_field_ids`를 늘리지 않았다. 새 항목도 모름/나중에/불완전 저장 가능하다.
- 선 플레이어 표식과 현재 행동자는 별개다. 표식이 움직이는 게임에서도 단순 재열기는 이동·라운드 종료·자원 지급을 실행하지 않는다.
- 공개 장면 속 뒷면 구성물은 위치/앞뒤와 정체를 구분한다. 비밀 덱을 펼쳐 사진을 찍으라고 요구하지 않는다.
- 봉인 확인은 내용의 정체를 안다는 뜻이 아니고, 미상 수량은0이 아니다. 저장하지 못한 과거 상태/효과를 만들어 채우지 않는다.
- 카드별 효과·권한 UI·장면 편집기·실물 인식·게임 규칙 엔진의 완성은 별도다. 외부 앱 게임은 해당 게임 앱의 저장을 대신하지 않는다.

## 재검사

```sh
node --import tsx tools/game-specs/cli.ts validate docs/research/game-specs-120/games --complete
node --import tsx tools/game-specs/essentials-check.ts
node --import tsx --test tests/game-essentials-data.test.ts
```

`prepare.py`는 사람이 작성한 scoped 결정 목록을 만든다. `apply.py`는 이 패키지의 baseline에 그 결정을 적용하는 재현 스크립트다. **다른 작업자가 원명세를 추가 변경한 뒤 apply.py를 실행하면 그 변경을 덮을 수 있으므로 다시 실행하지 않는다.** 이번 인계 후 원명세 쓰기를 동결한다. 제품 런타임 생성은 별도 담당이 수행한다.

공식 PDF/추출 텍스트는 공개 열람·로컬 연구 근거이며 출판사 저작권은 유지된다. 재배포/모델 학습/상업 아트 라이선스를 확보했다는 뜻이 아니다. 원본 링크/기존 로컬 자료를 우선 사용했고, 직접 조회 실패는 `downloads*.json` 및 남은 요청에 남겼다.
