# 남은 확인 요청 — 게임별 범위

기존 검토표의 추정/미확인 50건은 공식 사실로 승격하지 않았다. 별도12건은 제품 런타임 범위여서 이 데이터 작업의 해결 대상으로 세지 않았다. 120종 전체 카드·효과·공개성 검증도 완료하지 않았다. 각 게임에 아래 근거가 추가되어야 보류를 줄일 수 있다.

## 실제 접근·판본 제한

- 파워그리드 Recharged: 공식 PDF는 web의 크기 제한, 일반 HTTP 다운로드403. 우회/다른 판본으로 대체하지 않고 순서·발전소 더미·현금 공개 항목 보류.
- 반지전쟁2판: Ares 공식 상품/다운로드 페이지403. 사냥 주머니/사건 덱의 선택 기본판 조항 확인 보류.
- 메이지 나이트: 확보된 자료는 Ultimate Edition이지만 선택 명세는 원 기본판 모드다. 확장 포함 페이지를 기본판 사실로 승격하지 않고 기본판 적/유적/지도 비밀면 확인 보류.
- 티켓 투 라이드: 공식 현행2025 PDF는 열렸으나 초기 티켓 규정이 구판과 다르다. 기존 북미 기본판의 실제 인쇄를 임의 변경하지 않았고 공개 장수 의무도 그 본문으로 확인 못 해 보류.
- 스톤 에이지: 공식 English PDF의 web 본문은 직접 열람했으나 shell 다운로드 연결거부. source receipt에 로컬 PDF 없음으로 기록.
- Dune Uprising: 낡은 direwolfdigital assets 주소404, 공식 resources HTML에 직접 연결된 CloudFront 원본은 다운로드/본문 확인 성공.1–2인Rivals/6인/CHOAM은 이번 사실 보완에 포함하지 않음.
