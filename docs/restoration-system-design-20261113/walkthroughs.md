# 대표 장면의 세로 관통과 공통화

각 예시는 **VERIFIED 현재 입력 → RECOMMENDATION 목표 동작**이다. 아래 목표 화면·정정 효과를 이번에 구현하거나 측정하지 않았다. 원사진의 작은 숫자·가려진 실물은 새로 전사하지 않았다. 모든 처리에서 원값·원 ID·bbox·receipt·owner는 유지한다.

## 1. Sagrada: 창문, 트랙, 카드와 토큰을 한 작업면에

**현재 입력.** [사진](../pro-review-20261113/photos/sagrada.jpg), 4응답. baseline/high/medium은 windows1·dice26·cards7·tokens8, low는 windows0·dice26·cards7·tokens8이다. low의 전경18개는 draft로 분류돼 있다. 최신 코드는 baseline native18, high/medium 추정격자18을 유지하고 low는 판 없는 표시격자18을 내지만 실제 판/정식 칸으로 세지 않는다. [E03–E05, E09](evidence.md)

**지식과 연결.** 창문 4×5, 패턴 인쇄와 실물 주사위 구별, 라운드 트랙, 도구/공개 목표/토큰 구역은 기존 공간 정의와 아트를 재사용한다. 트랙 한 칸에 여러 주사위가 있을 수 있으므로 x방향마다 새 라운드를 부여하지 않는다. 도구에 부착된 토큰은 카드 identity와 함께 묶는다. 패턴의 색/수는 아트 제약이며 지금 놓인 주사위가 아니다. [공식 구조 근거 E10](evidence.md)

**장면 해석.** 전경 창문, 상단 트랙, 카드 두 줄, 토큰 무리를 서로 다른 region으로 만든다. 카드의 도구/목표 역할이 불확실하면 행 위치와 읽힌 역할을 대안으로 보존한다. 기존 추정기가 보존한 window/native 주소는 그대로이다. low는 `display-region / boardEntityId:null`이고 role 후보가 window이다. 원래 draft 관측을 window 관측으로 재작성하지 않는다. holes는 빈 셀 확정이 아니라 ‘관측된 주사위 없음’으로 남겨 구별한다.

**전체 평면.** 위쪽에 트랙, 가운데 공용 카드/토큰, 아래쪽에 읽기 좋은 전경 격자를 둔다. 사진의 사다리꼴을 직사각 격자로 펴되 source map을 유지한다. 카드/트랙에는 읽히지 않은 숫자를 만들지 않는다. 좁은 화면에서는 구역 jump와 가로 작업면을 제공하고 모든 구성물을 한 화면폭에 맞추기 위해 주사위를 축소하지 않는다. 기존 도구/트랙·창문 필드가 하나의 scene에 나타난다.

**최소 정정.** 정상 응답은 자동 상태로 바로 저장할 수 있다. low에서 필요하면 전경 구역을 한 번 선택해 ‘창문 영역’ 역할을 확인한다. 이는 18개 주사위의 표시 recipe를 한 번에 바꾸는 작업이며 판 identity/20정식주소/owner를 동시에 확정하지 않는다. 원근 때문에 그리드 축만 틀렸다면 구역 방향 또는 frame 하나를 정정한다. 각 주사위마다 칸을 지정하게 하지 않는다. 값 오독이 있는 주사위만 기존 편집기로 수정한다.

**저장·실물 정리·재개.** 창문의 배치와 트랙의 동일 라운드 묶음, 도구 토큰 부착을 기존 보존 template에 연결한다. 창문을 그대로 보관하는 방법과 사진으로 복원하는 방법을 구분해 표시한다. 트랙의 가시 주사위만 보고 현재 드래프트 차례/라운드를 계산하지 않는다. 기존 round/turn/pending 메모가 필요한 때만 확인한다. save intent snapshot에 관계/미확정까지 저장하고 재개 시 같은 구역과 값 편집을 복원한다.

**남는 한계.** low의 미검출 창문 자체, printed pattern의 정확한 identity, 가려진 값은 표시 개선으로 복원되지 않는다. role을 확인한 행위만으로 검출 정확도가 증가했다고 평가하지 않는다. 새 판독/원사진 추가가 필요한 항목과 표시만으로 해결되는 항목을 나눈다.

## 2. Lost Cities: 양편 원정과 공용 버림을 함께

**현재 입력.** [사진](../pro-review-20261113/photos/lost-cities.jpg), baseline42·high43·medium43·low46관측행. 원정 상당수는 `__photo.public`, 버림은 `discard.scene`으로 나뉜다. baseline은 최신 고정 비교에서 41맞음/1유보이고 같은줄쌍63/63이다. medium의 42유보는 좌표/대응 자료가 약한 문제를 포함한다. 값과 sourceArea를 모두 올바르게 읽었다는 뜻은 아니다. [E03–E05, E09](evidence.md)

**지식과 연결.** 기존 LC art의 색별5열과 버림5칸을 이용하되 관측된 양편에 열 recipe를 반복한다. 축은 사진의 세로축이 아니라 관측 공용판 frame/버림 중심선·줄 방향에서 구한다. 현재 A/B는 판 로컬 양편 표식이며 사람 owner가 아니다. 카드의 실제 노출/겹침과 부분 순서를 지키며 숫자 합법성으로 정렬하지 않는다. [공식 구조 근거 E10](evidence.md)

**장면 해석.** 공용판·버림을 중앙 region, 각 관측편의 원정 무리를 두 side region으로 만든다. 기존 fitted line·색 모름 줄·connected tail 연결을 재사용한다. 색이 읽히지 않은 카드도 같은 노출띠와 유일한 줄 근거가 있으면 그 줄의 표시 그룹에 둔다. 다른 편과 경쟁하면 side claim을 유보한다. 원정 role과 discard role은 같은 색이라는 이유로 합치지 않는다.

**전체 평면.** 가로로 펼친 색별 원정, 가운데 버림행, 반대편 원정의 구조를 만든다. 두 편의 카드를 모두 독자가 읽는 방향으로 보여 주되 ‘A쪽/B쪽’과 원래 물리 방향을 별도 표시한다. 이 upright 변환으로 실물의 순서가 뒤집히지 않는다. 하나의 긴 원정은 겹침/펼침 표시를 써 숫자가 읽히게 한다. 사진의 원근 거리 때문에 반대편 카드를 작게 만들지 않는다.

**최소 정정.** 한 줄이 잘못된 편이면 줄 단위로 A/B 또는 판을 지정한다. 색 한 장 미확정이 있어도 줄의 grouping을 유지하고 값 수정은 그 카드만 선택한다. 겹침이 유보된 구간은 줄 전체 정답을 추측하지 않는다. 수동 예외가 이미 있는 카드는 자동 전파에서 보호한다. 공용 버림과 원정이 다른 field여도 한 화면에서 선택할 수 있고 같은 scope의 묶음 수정은 한 transaction이다.

**저장·실물 정리·재개.** 각 원정/버림을 기존 template의 보존 묶음에 연결한다. 보이는 위 카드만 읽힌 더미는 아래 카드의 장수/순서/값을 만들어 저장하지 않는다. 그대로 묶어 보존하면 그 사실과 재배치할 위치를 기록한다. 같은 snapshot에서 양편/색줄/순서 유보가 유지된다.

**남는 한계.** far-yellow의 노출면과 관측행 대응, 일부 red discard 하부, medium bbox는 이번 구조 설계로 해소되지 않는다. 기존 원장에서는 이 유보를 유지한다. 새 read 없이 baseline과 같은 수준으로 ‘정답 처리’하지 않는다. 공용판이 안 보이고 버림도 비어 있는 새 사진에서 현재 fitted-line 방식이 충분한지는 새 반례에서 확인해야 한다.

## 3. 7 Wonders: 관측4판과 판 없는 구역을 상대 배치로

**현재 입력.** [사진](../pro-review-20261113/photos/seven-wonders.jpg)은 앞/왼쪽/오른쪽/위쪽 두 영역으로 구분 가능한 테이블이다. 응답은 wonder4·cards86·coins17·military10, 총117행이며 모두 한 공개 photo field다. 현재 공간 정의는 없고, 최신 결과는 groups45/boardContexts4/unassigned43이다. 고정 대응97판단가능 행 중74연결맞음/23미연결, 나머지20유보다. 사진의 전체 실물 정답 분모가 아니다. [E02–E05, E09](evidence.md)

**지식과 연결.** 기존 board asset의 tableModel, 도시 색줄, 불가사의 밑 단계, 자원/군사 구역을 profile로 사용한다. 실제 이웃 순서는 사진의 x순서와 같지 않다. 뒷면 카드는 단계에 끼운 카드인지 아직 손/전달/더미인지 분리한다. `GIZAH (A)`와 2판 팩의 차이 가능성이 있으므로 판본별 단계 효과/정식주소는 확인 전 유보한다. 공통적인 도시 무리와 끼움 표시는 가능하다. [공식 구조 근거 E09–E10](evidence.md)

**장면 해석.** 관측된4판을 중심으로 현재 유효 연결을 보존한다. 상단 왼쪽에 판이 검출되지 않은 카드줄은 상대 geometry/연결 구조가 지지하는 표시 구역으로 묶는다. 이 구역에 이름을 붙여도 실제 다섯 번째 판 관측을 추가하지 않는다. 상단 오른쪽 일부/오른쪽1개처럼 기존 연결이 부족한 경우는 해당 원인에 따라 후보 board/region을 남긴다. 떨어진 coin pile은 몇 cm 가깝다는 이유만으로 도시에 넣지 않는다. 손/팔에 의한 가림은 물체 경계 근거의 약화로 처리한다.

**전체 평면.** 예시 macro 구성은 다음과 같다. 위치는 이 사진의 관측 관계를 설명하는 그림이며 구현 상수/새 정답은 아니다.

```text
 [위 왼쪽 카드 구역: 판 미관측]    [위 오른쪽 판/도시]

 [왼쪽 판/도시]       [공용·소속 미확정]       [오른쪽 판/도시]

                       [앞쪽 판/도시]
```

각 패널 안에서 불가사의·색별 도시줄·끼운 단계카드·군사/동전을 정돈한다. 모든 패널을 세로 목록으로 만들지 않고 위/아래·양옆 관계를 보존한다. 카드 읽기 크기를 유지해 작업면이 넓어지면 pan한다. 작은 overview를 누르면 해당 도시로 이동한다. 실제 원형 이웃 관계가 불명인 상태에서 단순 화면 인접을 게임 이웃으로 저장하지 않는다.

**최소 정정.** 누락판 구역은 자동 표시만으로 유용해야 한다. 필요하면 사용자가 한 무리를 특정 관측판에 연결하거나 별도 구역으로 확정한다. 그 답은 관련 행 전체에 전파하되 detached coins/경쟁 group은 자동 포함하지 않는다. 사람 이름은 선택사항이며 전체5영역마다 필수 owner 등록을 요구하지 않는다. stage 오분류는 묶음 역할 수정, 숫자/색 오독은 기존 편집으로 분리한다.

**저장·실물 정리·재개.** 도시별 색줄과 단계에 끼운 뒷면 카드를 별도 보존 묶음에 연결한다. 보이지 않는 단계카드의 앞면은 채우지 않는다. 시대/드래프트 전달 단계/현재 처리중 행동은 기존 메모를 우선 사용하고, 정리 전에 실제 재개에 필요한 빈 문맥만 짧게 확인한다. neighbor 정보가 없으면 모르는 상태로 저장한다. reopen 시 실제4판과 표시 구역의 차이가 그대로 유지된다.

**남는 한계.** 보이지 않는 판의 모양/단계, 정확한 판본, 가려진 카드 수, 떨어진 동전의 실소유, 원형의 정확한 좌석 순서는 새 자료 없이는 해결할 수 없다. 미연결→표시구역 편입은 사용자 가독 개선이며 실제판 membership 정답 증가로 계산하면 안 된다.

## 4. 다른 구조군과 native 경계

| 구조군 | 공통 recipe/renderer | 재사용 우선·확정하지 않을 것 | 최소 새 반례 |
|---|---|---|---|
| 격자/개인판 | board-local grid + sparse occupancy + region hypothesis | 기존 slots와 수동/native 위치. 같은 색 주사위를 구멍 없이 채우지 않음 | 두 판 회전 다름, 희소 배치, 잘린 판, 인쇄와 실물 겹침 |
| 노선/경로/network | node/edge topology + 선로 점유 + label | 실제 network asset의 연결을 재사용. 가까운 선로로 강제 snap 금지 | 교차하지만 연결 아닌 선로, 가려진 junction, 동일색 다른 노선 |
| 트랙 | tick/slot + 여러 점유 허용 + 방향 claim | 트랙 인쇄 번호와 현재 상태 분리 | 같은 칸 여러 말, 순환 트랙 원점 가림, 보드 180도 |
| 시장/공용열 | row/slot + face/stack + boardless grouping | 공급 빈칸·뒷면·불명 칸 구별 | 앞/뒤 혼합, 비어 보이는 가림 칸, 떨어진 카드 |
| 카드줄/더미 | overlap/partial-order + role | 읽힌 숫자 순으로 정렬 금지, hidden count 유보 | 같은색 분리줄, 역방향 노출, 바닥카드 가림 |
| 개인판/원형 좌석 | repeated region + explicit neighborhood | pane 위치와 사람/게임 이웃 분리 | 판 누락, 양옆 비슷한 카드, 사진 밖 좌석, 손 가림 |
| 자유 배치 | 지역 무리 + loose tray + 원본 연결 | 의미 정보가 없으면 false precision 없이 기존 field 표시 | 규칙 아트에 없는 메모/토큰·혼합 패턴 |
| Catan native | 기존 hex/edge/vertex와 지도 렌더러를 scene의 주 패널로 사용 | generic network로 native identity/수동값 대체 금지 | 정식 frame와 자유 photo 혼합, edge/vertex 경쟁, 구판 저장본 |
| Rummikub native | 기존 확정 groups/순서 + loose tile 영역 | 같은 숫자/색이 여러 장인 실물 구분 유지 | 기존 수동 그룹 + 미연결 타일 + 중복값 + 부분가림 |

120종 기본 경로는 지금 있는 필드/도해/읽기 정책을 유지한다. 새로운 구조군 adapter를 추가할 때 해당 family의 새 장면을 검증하고 재사용한다. 세 사진의 구체 좌표·ID·정답 그룹 수를 코드에 내장하지 않는다. native를 ‘공통화’라는 이유로 퇴행시키지 않는다.
