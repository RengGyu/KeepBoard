# 실제 독립 근접 촬영 — 영상 기반 후속 시도

기존 사진 후보 26장/유효쌍 0 기록은 그대로 보존했다. 이번에는 공개 영상에서 실제 카메라가 움직이고 평가 대상 실물이 그대로인 구간을 찾는다. 원본 crop을 독립 촬영으로 세지 않는다. 제품·게임팩 변경은 없다.

**현재 측정 2게임 / 입력 부족 8게임.** 총 실제 6회 HTTP200/STOP, 재시도0, 각 게임 동시3회. 약10종 목표를 달성했다고 표시하지 않는다. 마지막 추가 후보까지 직접 프레임을 확인했으며, 적합하지 않은 자료로 요청 수를 채우지 않았다. 미측정 8게임은 성능 실패가 아니다.

|게임|W/C/D 개별 표본 대응|W/C/D 맞힌 속성|W+D가 W+C보다 새로 제공한 정답 정보|모델 벽시간|
|---|---|---|---|---|
|Splendor|12 / 12 / 12 (각12개 중)|16 / 15 / 16 (각18값 중)|없음: 각 조건 합집합 상한16값으로 동일|21.872초|
|Quacks|0 / 8 / 0 (각8개 중)|0 / 15 / 0 (각16값 중)|없음: 합집합 상한 W+C15값, W+D0값|14.681초|

이 두 사례의 **W+D 대 W+C 추가 정보 이득 있음0 / 없음2 / 입력 미확보로 미측정8**이다. D 단독이 C의 오류 하나를 회복한 Splendor도 그 값은 W가 이미 맞혀 추가 정보는 아니었다. 결과를 보고 조건·프롬프트를 바꾸거나 재호출하지 않았다. 한 번씩의 부분 표본 비교이므로 독립근접 일반 무용론이나 인과효과를 뜻하지 않는다. 위 시간은 모델 요청 구간이며 자료검색·촬영·정정·앱 전체 소요시간이 아니다.

## 첫 실제 측정: Splendor

[Rahdo 공개 실물 영상](https://www.youtube.com/watch?v=HlOxEk3_yuc) 28.5초 W와 44.5초 D. 1080p 원본 프레임을 사용했다. 카메라가 접근하는 동안 같은 시장 카드 12장의 배치·그림이 유지된다. 다뤄진 귀족은 평가 대상에서 제외했다. C는 W의 `[350,270,1620,840]` 무손실 crop(1270×570)이다. W/D는 각각 1920×1080. D는 더 크게 보이지만 초점이 다소 흐리다.

요청 전에 동결한 **AI 부분 시각참조**는 카드 12장, 보너스 12값+명확히 보이는 인쇄 점수 6값이다. 사람의 인증 정답이나 전체 사진 정확도가 아니다. 빈 점수는 0으로 추정하지 않았고 비용·단계·소유자·스택 수량은 평가하지 않았다. 참조 SHA `9b2c95be2a8c463d7071206c2469d936cb2bc9b5c2001cd672c8007898021d60`.

|조건|개별 카드 대응|맞음/18|오독|모름|시간|입력/출력/총 토큰|
|---|---:|---:|---:|---:|---:|---|
|W 전체|12/12|16|0|2|21.574초|1718 / 3052 / 4770|
|C 원본 crop|12/12|15|3|0|20.023초|1696 / 2810 / 4506|
|D 독립 근접|12/12|16|2|0|21.853초|1718 / 3019 / 4737|

**D는 C의 보너스 오독 한 개를 회복했지만 W보다 새로 맞힌 값은 없었다.** C/D 모두 명확한 점수 두 개를 0으로 읽었고 W는 모름으로 남겼다. 한 조건 한 번이므로 우열·인과·일반 정확도를 확정하지 않는다. 세 요청 동시수 3, 전체 벽시간 21.872초, HTTP200/STOP 3회, 재시도 0. 사고 토큰은 공급자 미보고이므로 null이며 실제 청구액은 미확인이다. 남은 호출상한 27회.

현재 generic Gemini 3.8 Flash/LOW/HIGH/32768의 프롬프트·스키마·설정을 그대로 사용했다. 세 prompt/config SHA 동일을 사전검사했고 다른 것은 사진 bytes 및 입력 provenance다. 예전 W 응답은 새 프레임과 요청이 달라 재사용하지 않았다. 인증은 제공된 upload 파일을 accessor에서 메모리로만 사용했다.

## 현재 제품 projection과의 구분

저장 응답을 `prepareScanObservation → analyzeScanUnit → projectScanResults`로 오프라인 재생했다. 외부 fetch를 금지하고 provider body 3개 SHA를 대조했다. W/W+C/W+D는 각각 편집 행 15개(평가 카드 12+deck 관측 3)로, 정답 총수가 아니다. 원문 receipts는 각각 1/2/2개다.

- W+C는 같은 원본 좌표로 연결된다. crop의 잘못 읽힌 점수 0도 후보값에 반영되므로 연결 성공을 정답 성공으로 부르지 않는다.
- W+D의 별도 source 관측은 `unregistered-view` 등으로 보존되며 무조건 새 실물로 합산되지 않는다. 다른 시점 자동 정합은 미구현이다.
- 본 시험은 실제 앱 세션 저장/브라우저 검사가 아니라 오프라인 현재 projector 검사다.

## 두 번째 실제 측정: Quacks

[BGG 공개 영상](https://www.youtube.com/watch?v=sKChFf4i8JA) 109–114초의 고정 공급칩/책을 실제 카메라가 훑는 구간이다. W112.5초, D110.5초로 **근접→전체 순서**다. 시간 방향을 숨기지 않으며, 같은 정지 실물을 서로 다른 시점·크기로 본 판독 비교다. 1920×1080 두 원본과 W의 `[230,120,900,420]` 무손실 C(670×300)를 사용했다.

응답 전에 녹색 공급 더미 앞쪽의 노출된 칩 윗면8개/색8+숫자8값을 고정했다. 아래 가려진 칩, 스택 수량, 책에 인쇄된 칩 그림, 다른 공급 물체는 평가하지 않는다. 참조 SHA `6b7dc26009f8859ea14d5a6fa93f798bc98a9e49fa746605722b2d8a2c4faa1f`.

|조건|개별 칩 대응|맞음/16|오독|물체 누락에 따른 속성 미회수|시간|입력/출력/총 토큰|
|---|---:|---:|---:|---:|---:|---|
|W 넓은 프레임|0/8|0|0|16|12.668초|1759 / 984 / 2743|
|C 원본 crop|8/8|15|1|0|14.657초|1759 / 1825 / 3584|
|D 독립 근접|0/8|0|0|16|9.485초|1759 / 968 / 2727|

W/D 원문 자체가 books5개만 반환했고 chips는0개다. 정규화 전후 종류별 개수도 동일하여 decoder가 칩을 버린 경우가 아니다. C 원문은 chips18+books2개이며 그 중 사전 표본8개가 개별 대응한다. 나머지 원응답을 자동 환각/정답으로 분류하지 않는다. 칩은 W/D 사진에도 보이지만 사진의 초점·구도·주변 책과 작업 지시의 상호작용, 실행 변동을 분리하는 실험은 아니므로 단순한 모델 시각능력 한계로 단정하지 않는다.

현재 제품의 오프라인 W+C는 표본8칩/15맞은값을 회수했고 W+D는 회수0이다. 전체 편집행은5→25/5로 다른 물체·부분 책 관측도 포함한다. 25행을25개 정답으로 세지 않는다. [information-vs-projection.json](information-vs-projection.json)은 **평가기준을 아는 정보 합집합 상한**과 **실제 제품 편집값**을 별도로 기록한다. 실제 제품에는 그 평가 oracle이 없다.

## 재현 자료

- `pilot-inputs.json`: 공개 출처·timestamp·입력 및 private 참조 locator/SHA. 사진/정답 bytes는 repository 밖에만 있다.
- `prepare-pilot.py`, `prepare-quacks.py`: 이미 사전 동결된 private 참조 SHA/좌표/입력/무손실 crop 검증. 기대값·물체 box를 repository 스크립트에 넣지 않는다. 원래 수동주석 생성 helper도 private 자료와 함께 보존했다.
- `run-pilot.mts`, `pilot-preflight.json`: 고정된 실제 제품 body, prompt/config/source SHA. `--execute`는 단일 실행 claim으로 추가 호출을 차단한다. **재실행 금지.**
- `pilot-ledger.json`, `pilot-execution.json`: 실제 HTTP/usage/시간/동시수. 키·인증 헤더는 저장하지 않는다.
- `score-pilot.py`, `pilot-results.json`: geometry-only 일대일 대응과 관측 속성 평가. 값으로 물체 매칭하지 않는다.
- `replay-pilot.mts`, `pilot-projection.json`: 저장 응답만 쓰는 현재 제품 경로. `node --import tsx docs/ten-games-closeup-20261029/video-attempt/replay-pilot.mts`는 모델 호출 0이다.
- `checkpoint.json`, `availability.json`, `verification.json`: 영상별 실제 선별 구간·hash·제외 이유·검사. 약10종 완료로 표시하지 않는다.
- `quacks-*`: 두 번째 사례의 입력/요청/ledger/결과/현재 제품 재생. private 원문은 repository 밖이다.

도구는 private venv의 공식 PyPI yt-dlp 2026.10.26과 기존 FFmpeg다. 정상 TLS·시스템 CA, 쿠키·로그인 없음. 앱 의존성/설정은 변경하지 않았다. 초기 네트워크 권한/DNS 및 cached section_end 추출 오류는 판독 실패와 별도로 기록했다.

측정 W/D는 YouTube 1080p의 필요한 짧은 구간을 FFmpeg로 정확히 잘라 재인코딩한 동일 클립에서 PNG로 추출했다. 해상도 확대·선명화는 하지 않았다. 원본 카메라 파일/무압축 화질은 아니며 영상 압축·초점 영향을 포함한다. C는 그 W PNG와 픽셀 단위로 동일한 crop임을 검사했다. 후속 Terra 비교는 별도 감독 카드까지 실행하지 않으며, 고정 입력/참조/요청/usage만 재사용 가능하게 보존한다.
