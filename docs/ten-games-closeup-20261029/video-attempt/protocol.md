# 공개 영상의 실제 독립 근접 프레임 비교 — 새 시도

이전 사진 availability 결과는 변경하지 않는다. 본 시도는 공개 영상의 시간 연속 구간에서 실제 카메라가 이동하고 물체가 정지한 W/D를 찾는다. 이전 사진26장 검사나 원본 crop을 새 측정으로 세지 않는다.

1. 첫 후보3개 이내에서 시작: Splendor Duel 설명 setup, Sagrada 설명/플레이 전 소개, Cascadia setup. 실제 프레임을 확보하기 전에는 적합으로 판정하지 않는다.
2. 컷·화면 전환·디지털 확대만 있는 구간, 물체 이동, CGI/디지털 보드, 대응 물체 불확실은 제외. W와D 사이 연속 중간 프레임을 직접 보고 주변 고유 배치를 대조한다. 정지 상태 주장은 평가 ROI에 한정하며, 밖의 hidden 상태를 추정하지 않는다.
3. 적합쌍에서 W의 ROI를 고정해 무손실 C를 만들고, W/C/D의 동일하게 읽을 수 있는 물체/속성, 사진별 box와 correspondence를 모델 결과 전에 private AI부분참조로 동결한다. 인간정답/전체사진 완전주석이 아니다.
4. 실제 제품의 기존 generic prompt/schema/model/settings를 유지한다. 원본 hash/영상URL/timestamp/픽셀크기, provider body hash와 필수 provenance 차이를 고정한다. 같은 요청인 기존W만 재사용 가능하다.
5. 호출상한은 이전 미사용30회, 자동재시도0. 유효쌍1개 파일럿 W/C/D(최대3회) 후 결과를 즉시 보고하고 확보가능한 나머지로 확장한다. 임의로 부적합10종을 채우지 않는다.
6. 개별 검출/종류/요청속성의 맞음·오독·unknown·누락, 원문과 현재 projection을 구분한다. 다른 source 자동정합은 미구현/N/A로 둔다. 입력/출력/thoughts/total usage의 미보고 필드는null, 호출시간과 실제동시수/벽시계를 기록한다. 촬영/수동정정시간은 실제관측 없으면UNKNOWN이다.
7. 다운로드/브라우저/자료 자체의 선행조건이 막히면 검색범위·실패·마지막가능대안을 감독에게 전달한다. 기존API0결과를 측정성과로 반복하지 않는다. 제품/판/기존GT/원응답 변경0.
