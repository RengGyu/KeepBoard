# 모바일 앱 화면 문구 정리 인계

작업일 2026-10-22. 작성: Claude(claude-opus-5-5).

정리 범위는 `src/**`에서 화면에 보이는 문구와 설명 렌더링뿐이다. 다음은 바꾸지 않았다.
- 서버, shared, 게임팩, 명세, 스키마
- 데이터 필드, 보관 조건(단계) 원문
- 저장·복원·PIN·후보·flush 로직

문구는 접어 두는 방식으로 숨기지 않았다. 출력 자체를 없애거나 짧게 줄였다.

## 그대로 둔 것
- **0과 모름 구분:** "아직 모름", "수량 모름", 수량 입력의 `모름` placeholder, "미확인 유지"를 그대로 유지했다.
- **실물 보관:**
  - 보관 항목의 순서·앞뒤·봉인 안내는 그대로 둔다. 예: "실물 순서와 앞뒤를 유지해 보관하세요."
  - 복원 순서와 "보관 조건 더 보기 +" 안의 **게임별 보관 단계 원문**도 그대로다. 감독 지시대로 조건 목록은 숨기지 않았다.
  - 보관 위치 입력과 저장도 바뀌지 않았다.
- **판본 선택:** 게임 선택 패널, 판본 표시, 지원 수준 배지를 유지했다.
- **PIN:** PIN 설정과 잠금 화면, "개인 기록 전에 PIN을 설정해 주세요"를 유지했다.
- **사진 읽은 뒤 후보 확인:** "읽은 타일 후보예요. 다른 곳만 고친 뒤 저장하세요." 같은 확인 문구를 유지했다.
- **복원 범위:**
  - 범위 안내 한 줄을 유지했다. "공개 기록만 복원해요. 개인 기록은 그대로예요." / "내 기록만 복원해요…"
  - 복원 전에 열린 초안을 먼저 저장하는 로직도 그대로다.
- **자동 판독 지원 표시:** 일반 게임은 "수동 기록 · 자동 판독 없음", 루미큐브는 "자동 인식이 꺼져 있어요"를 한 줄로 보여 준다.
- **전용 팩 질문의 확인 이유:** 카탄·루미큐브 질문의 이유 문구는 유지했다. 일반 팩의 이유는 공통 상투문이나 명세 rule 요약이라 지웠다.
- **오류 메시지:** 카메라·전송 오류 같은 드물게 나오는 오류 문구는 그대로다. 행동 안내가 필요하기 때문이다.
- **기능 동작:** 검색, 탭, 기록, 저장, 그림, 가로 탭, 초안, global flush, 후보 계약은 로직을 바꾸지 않았다.

## 한계
- **브라우저 확인 안 함:** 이 세션에는 CUA·브라우저 도구가 없다.
  - 키 없는 새 임시 미리보기에서 390px로 루미큐브와 일반 게임 1종을 보는 확인은 하지 못했다.
  - 화면 확인은 SSR 텍스트 출력으로만 했다.
  - 스크린샷은 없다.
- **확인하지 못한 화면 상태:**
  - 저장본이 있을 때의 "저장 기록 복원 +" 영역
  - 개인 탭에서 PIN을 해제한 뒤의 GameEssentials
  - 스캔 창 실제 모습
- **스타일 정리 안 함:** 쓰이지 않게 된 CSS 규칙(`.runtime-support`, `.scan-explanation`)은 다른 세션과 충돌하지 않도록 그대로 두었다.
- **남은 명세 문구:** "보관 조건 더 보기 +" 안의 조건 목록에는 shared 명세에서 온 문장이 일부 남아 있다. 예: "내용을 모르면 펼쳐 확인하지 않고 물리 묶음/소유자와 메모만 남긴다.", "내용을 펼치거나 JSON으로 입력하지 마세요."
  - 실물 보존 단계라서 감독 지시대로 숨기지 않았다.
  - 문장을 다듬으려면 shared 또는 명세를 바꿔야 하므로 이 작업 범위 밖이다.

감독 CUA 확인을 권하는 순서:
1. 390px에서 루미큐브 보드를 열고 공용 보드 확인 → 플레이어 탭 → PIN
2. 일반 게임(예: 카르카손) 새 판 → 게임 기록 → 실물 보관·복원 → 저장
3. 저장 후 "저장 기록 복원 +" 영역 확인

위 파일들의 소유권을 반환한다. commit, push, deploy는 하지 않았다.
