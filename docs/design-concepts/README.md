# KeepBoard UI 시안 A·B

현재 앱(`src/`) 위에 덮어씌우는 CSS 시안입니다. 앱 기본 화면은 바뀌지 않습니다.
글자 크기, 페이지 구성, 기능, 승인한 만화풍 이미지 4장은 그대로 두었고, 바꾼 것은 색, 배경, 버튼, 헤더·히어로 구조, 제목 글꼴, 움직임입니다.
유료 AI 이미지 생성 없이 CSS 그라데이션과 인라인 SVG로만 장식했습니다.

| 파일 | 내용 |
| --- | --- |
| `concept-a-paper-board.css` | 시안 A · 말판 스티커: 크림 판지 배경과 옅은 주사위·육각 무늬, 남색 잉크 테두리, 딱딱한 오프셋 그림자, 초록 시작 버튼, 상자 뚜껑식 좌우 분할 히어로, 제목 글꼴 Black Han Sans |
| `concept-b-cartoon-lobby.css` | 시안 B · 토요일 아침 만화: 하늘색 로비, 떠 있는 둥근 HUD 헤더, 그림 위에 겹친 말풍선 카피, 구름 밑단과 흘러가는 구름, 젤리 버튼, 세이브 슬롯 카드, 제목 글꼴 Jua |
| `sheet-*.jpg` | 390×844·1440×1000 실제 앱 캡처(홈, 저장 피드백, 첫 촬영, 보드 편집) |

움직임은 모두 `prefers-reduced-motion: reduce`에서 꺼집니다.

## 미리 보기
`npm run dev` 뒤 브라우저 개발자 도구에서 시안 CSS 파일 내용을 `<style>`로 붙이거나,
Playwright `page.addStyleTag({ path })`로 주입해 확인합니다. 시안을 고르면 `src/styles.css`에 반영하고 이 폴더는 정리합니다.
