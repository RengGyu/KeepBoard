# 만화풍 보드게임 원화 · Part B

## 촬영 방향 오류 수정 v3

명시적으로 허용된 built-in edit 1회로 [capture-guide-v3.png](../../../../public/brand/cartoon-v2/states/capture-guide-v3.png)를 별도 저장했다(1254×1254 RGB PNG, 2,157,012 bytes). 한 줄 의도는 “후면 카메라는 판 쪽으로, 앞면 화면은 관찰자 쪽으로 향하게 한다”이다. [실제 edit 프롬프트와 검수 기록](edit-v3.json).

저장된 v3를 직접 열어 앞면 베젤·파란 화면·희미한 게임판 미리보기가 보이고, 관찰자 쪽 후면 렌즈와 플래시가 사라졌음을 확인했다. 손·가로폰 위치·게임판·구도·색·그림체는 시각적으로 유지된다. 화면에 문자나 앱 버튼은 보이지 않는다. 뒤쪽 렌즈가 가려진 상태라 촬영 방향은 앞면 화면과 미리보기로 전달된다. 픽셀 단위의 무변경이나 기하학적 평행성의 실측은 보증하지 않는다. 원본 v2와 box v2의 해시 불변을 확인했고 앱에는 적용하지 않았다. 아래 v2의 한계 기록은 이력을 위해 유지한다.

built-in `image_gen`을 정확히 두 번 별개 호출해 참조 이미지 없이 새 장면을 생성했다. 제품 참조는 변경하지 않았다. 기존 아트도 덮어쓰지 않았다. 실제 제출 프롬프트 전체·의도·크기·형식·해시·검수 한계는 [generation.json](generation.json)에 있다.

| 원화 | 한 줄 의도 | 실제 파일 |
|---|---|---|
| ③ capture-guide-v2 | 손으로 휴대폰을 들고 멈춘 일반 보드게임을 기록한다. | [PNG](../../../../public/brand/cartoon-v2/states/capture-guide-v2.png) · 1254×1254 RGB · 2,295,500 bytes |
| ④ save-box-v2 | 말·카드·주사위·표식을 무표지 상자에 모아 보관하고 다시 꺼낸다. | [PNG](../../../../public/brand/cartoon-v2/states/save-box-v2.png) · 1254×1254 RGB · 2,330,874 bytes |

공통 스타일 프롬프트는 두 호출에 정확히 동일하게 사용했다: `slightly anime-inspired casual board-game illustration, stylized 2D, hand-drawn clean contours, rounded shapes, gentle cel shading, lively but restrained, collectible game-art character appeal`.

**VERIFIED:** 저장된 두 PNG를 직접 열었다. 외곽선과 셀 음영의 2D 만화풍이며, 파랑/코랄 말과 크림 카드·주사위·원형 표식이 구분된다. 눈에 띄는 문자·워터마크·기기 UI·게임 로고·인물 얼굴은 없다. 원본 파일을 수정하지 않고 프로젝트 경로로 복사했다.

**PARTIAL — 촬영 안내:** ③은 휴대폰 뒷면과 렌즈가 관찰자 쪽으로 보인다. 판을 향해 촬영하는 정확한 방향이 불명확하므로 **촬영 자세를 안내하는 최종 원화로 확정하지 않는다**. 요청보다 사선 시점과 테이블·식물 장식도 강하다. 생성 프롬프트에서 화면/UI를 피하려고 휴대폰 뒷면을 지정한 선택이 이 한계에 기여했다. 승인된 두 장을 초과해 다시 생성하거나 편집하지 않았다.

**UNCLEAR:** 두 그림 모두 실제 앱의 작은 크기·크롭·배경 합성은 확인하지 않았다. ④는 보관 서사가 읽히지만 배경 장식과 말의 하이라이트가 요청보다 강하다. 전체 게임 IP와의 비유사성이나 실제 게임 상태의 정확한 재현은 보증하지 않는다. 앱 적용 전 시각 선택과 ③의 촬영 방향 검토가 남아 있다.
