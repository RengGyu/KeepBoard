# 호스팅 비교: 부분 결과

실제 요청은 **4/6회**, 자동 재시도 0회다. 남은 2회는 실행하지 않았다. 제품·기존 기록·배포·결제 설정은 변경하지 않았다.

| 요청 | 결과 | 클라이언트 시간 |
|---|---|---:|
| Gemini 최초 OCR | HTTP400: 실행기 키 파서가 전체 토큰을 보존하지 못함 | 0.657초, 오류 왕복 |
| Florence OCR | HTTP200, 원문 영역 1개 | 8.242초 |
| Florence 구성물 위치 | HTTP200, 영역 3개 | 2.430초 |
| Gemini 수정 후 OCR | HTTP429: 프로젝트 월 지출 상한 초과 | 0.675초, 오류 왕복 |

키 파서는 완전한 토큰을 보존하도록 교정했고 합성 검사 **20/20**이 통과했다. 실제 키 값·접두·해시는 기록하지 않았고 원본 키 파일도 변경하지 않았다. 새 키 발급은 현재 해결책으로 요구하지 않는다.

수정 후 Google 메시지는 **“Your project has exceeded its monthly spending cap.”**이다. 기존 프로젝트의 [AI Studio spend 설정](https://ai.studio/spend)이 확인 대상이다. 잔액·실제 청구·계정 tier는 조회하지 않았으며 상한/결제를 변경하지 않았다. 일반 시간당 rate limit이나 모델 품질 실패로 분류하지 않는다.

Florence OCR은 고정한 카탄 숫자 18개 부분집합에서 **1개 일치·17개 미검출**, 오독/미상/대응모호 0개였다. 정답값으로 재매칭하지 않고 원본 사각영역과 고정 중심점의 상호 유일 포함으로 대응했다. GT 중심은 타일 중심이므로 토큰 경계 IoU 정확도를 뜻하지 않는다. 전체 인쇄문자의 완전한 GT는 없으며 미주석 문자를 자동 오검출로 세지 않았다.

구성물 출력은 `desk`, `person`, `plate` 3개다. 전용 GT가 없으므로 **정성 관찰·미채점**이며, 게임 실물 종류를 정확히 판독했다고 주장하지 않는다. Florence native finish/실제 weight revision은 응답에 없어 UNKNOWN이다.

제공자 처리 시간은 OCR 0.1274초/구성물 0.3337초다. 합계 약 **0.0009223 credit**은 응답 time÷500의 추정치이며 실제 청구 credit/USD는 UNKNOWN이다. 클라이언트 왕복 시간과 청구 실행 시간은 다르다. Gemini 모델 응답·usage가 없으므로 **모델 간 우열이나 문맥 효과를 비교할 수 없다.** 한 장의 개발용 사진 결과를 다른 게임으로 일반화하지 않는다.
