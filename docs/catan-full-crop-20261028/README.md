동일 사용자 사진을 보드 전체가 포함되는 네 구역으로 나눠 `gemini-3.8-flash` LOW 추론 / HIGH 이미지 / 출력 상한 32768로 병렬 4회 실행했다. 재시도 0, 앱·운영 기록 쓰기 0. 요청 전에 `plan.json`과 네 request SHA를 고정했다. 원본과 crop/request/native 본문은 private 경로에만 있다.

실측: **25.796초**, 입력 **5,196**, 출력 **7,838**, 총 **13,034 tokens**. 네 요청 모두 HTTP 200/STOP. 생각 토큰 필드는 네 응답 모두 없으므로 0이라는 집계값을 내부 연산 0의 증거로 해석하지 않는다. 통화 청구액은 확인하지 않았다.
