# 전체 사진 + 부분 사진 병렬 실측

운영 서비스에서 한 작업으로 전체 사진 1장과 고정 수동 crop 4장을 읽는다. 제품이 자동 분할했다고 해석하지 않는다. 서로 다른 시점의 실제 근접 촬영은 이 시험에 포함하지 않는다.

- 입력: 이전 한 장 시험과 같은 JPEG, SHA `28ce72a474b4cd06f0995427a53a1c8ab815e0c3e3fa656143f91836c8254dbc`.
- 실행: 한 job, 최대 2 unit 동시 실행, 5개 계획 unit, 자동 재시도 0.
- 제품 소스/판독 지시/모델/출력 계약 변경 없음. 25개 동결 해시를 확인했다.
- 기존 서비스의 첫 anchor native 판독과 crop literal 판독을 그대로 실행한다. 새 프롬프트나 모델을 만들지 않는다.
- 시간: `clientReadMs`는 job POST 시작(준비 포함)부터 완료 응답 관측까지, `timings.totalMs`는 서버 job 시간이다. `providerMs`는 병렬 요청들의 합계이며 대기시간이 아니다. 사진 업로드는 별도 `uploadMs`; 이 시험 스크립트는 다섯 업로드를 순차 등록했으므로 앱 UI 업로드 성능이라고 하지 않는다.
- 정확도: 응답을 보기 전 직접 관찰한 지형·숫자 기준표와 비교한다. 겹침·가림이 있는 건물/도로 총수는 미확정이며 전체 정확도 백분율을 만들지 않는다.
- 저장: 수정 없이 저장·재개 후 그림/관측 기록과 모든 원본 bytes가 같은지 검사하고 자체 시험 기록만 정상 보관 처리한다.

진행 상태 및 수치: [result.json](result.json). 재실행 방지 sentinel이 있으므로 스크립트를 다시 실행해 유료 작업을 중복 발행하지 않는다.

## 실측 완료 — 품질/30초 목표 실패

서비스 작업 1회, 계획된 판독 5개 모두 완료, 재시도0.

| 측정 범위 | 시간 |
| --- | ---: |
| 서버 job `totalMs` | 87.658초 |
| 준비 `prepareMs` | 14.169초 |
| job 요청 시작부터 완료 확인 `clientReadMs` | 112.026초 |
| 사진 5장 순차 등록·업로드 (별도) | 47.718초 |
| 위 업로드부터 완료 확인까지 | 159.744초 |

개별 unit 경과는 34.64/25.75/19.57/16.23/9.05초이고 provider 합계는99.660초다. 서버 작업 시간과 provider 합계는 병렬 실행이므로 같은 값이 아니다. 이전 원본1장 job64.011초와 직접 비교할 공통 범위는 이번 서버 job87.658초이며, 서로 다른 호출의 응답 변동도 포함한다. 112.026초에는 준비·제출·완료 polling 비용이 들어간다. 사람이 촬영/선별하는 시간은 포함하지 않았다.

기준 사진은40개 관측(지형19/숫자17/도둑1/마을2/도시1), 부분 사진 원문은 각각41/24/15/6개 관측이다. 겹친 관측을 실물 수로 합산하지 않는다. 최종 그림은37개(지형19/숫자15/도둑1/마을1/도시1)이며 도로0개다. 부분 사진의 도로 관측은 존재하지만 부분 사진에만 있는 실물을 자동 추가하지 않는 현재 규칙 때문에 그림에 추가되지 않았다. 색상/종류 충돌 그룹을 건너뛰는 분기 때문에 기준 사진의 숫자2개와 건물1개도 최종 그림에서 제외됐다. 원문은 보존됐다. 해당 분기는 `server/scanObservation.ts`의 `projectScanResults`, `if(link.status==='conflict')continue`와 anchorMember 조건이다.

독립 시각 주석의 회전된6/9 한 개는 모호함으로 제외했다. 최종 그림에서 명확한 숫자16개를 위치별 대조한 결과12개 일치,1개 값 불일치,3개 해당 위치 없음/좌표 오류다. [검사 상세](number-check.json). 이는 숫자 일부의 국소 검사이며 전체 게임 정확도나 반복 평균이 아니다. `missing-at-reference-position`에는 실제 미검출과 잘못된 box를 모두 포함한다.

수정 없이 저장·재개 후 그림과 모든 관측 기록이 그대로이며, 원본5개 bytes 해시도 동일했다. 자체 시험 기록만 보관 처리했다. 모델/프롬프트/출력 계약/제품 코드는 변경하지 않았다. 추가 유료 호출 없이 이 응답으로 결합 문제를 확인했다.
