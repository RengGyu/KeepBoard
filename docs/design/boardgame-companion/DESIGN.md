# KeepBoard — 보드 중심 시안

## 목적과 범위
사진 추가 → 그림에서 빠른 정정 → 공용 보드/개인 보유 분리 → 필요한 차례·메모만 저장 → 같은 판 재열기. 제품 구현 전 독립 HTML/SVG 시안이다. 예시 인물·보드·카드만 사용하며 실카메라·AI·제품 API를 호출하지 않는다.

## 선택한 방향
**밝고 조용한 작업면 위에 실제 타일과 말을 크게 놓는다.** 게임의 성격은 기존 ComponentArt와 카르카손 타일에서 얻는다. 나무 배경, 장식용 패널, 구호, 통계 대시보드는 넣지 않는다. 짙은 초록을 공통 행동색으로 쓰고 플레이어색은 이름/말 형태와 함께 표시한다.

첫 화면은 내 보드와 이어할 판. 편집 화면의 중심은 보드 하나. 기존 수정과 추가는 분리한다. 추가에는 말 / 타일·숫자 / 카드·기타의 세 탭을 둔다. 선택한 부품만 관련 설정을 보여주며 다중선택은 공통 소유색 변경·삭제·전체 해제만 제공한다. 이동·교환·삭제는 Undo로 되돌린다.

390px에서는 보드 아래 조작면과 하단 저장, 1440px에서는 보드 오른쪽 조작면을 쓴다. 공용/개인 전환은 보드 문맥 안에 둔다. 개인 내용은 기본 가림, 명시적으로 열기, 공용으로 나가면 다시 가림을 시연한다. 이는 실제 계정 인증 구현이 아니다.

## 시각·상호작용
- 글자 16px 기본, 보조 14px, 모든 버튼/입력 44px 이상. 색 외 이름·선택 체크/윤곽을 함께 사용.
- 사진/그림 전환, 선택 시 조작면 160ms 등장, 저장 상태의 짧은 전환. reduced-motion에서는 제거.
- 키보드로 주요 조작·부품 목록·다이얼로그 접근. 보드의 작은 부품은 44px 선택 버튼과 별도 목록을 같이 제공.
- 추가 순서: 종류 → 해당 설정 → 보드 자리 → 놓기. 저장은 불완전/모름 값도 허용.

## 실제 코드에서 확인한 개선 지점
`src/App.tsx`의 큰 홍보 문구/장식 보드/카드 목록이 실제 내 보드보다 먼저 나온다. `SessionWorkspace.tsx`는 촬영·그림·자산·맥락을 순서대로 길게 쌓는다. `SceneEditor.tsx`는 모바일 버튼이38px/소유색36px이고 선택 양식이 보드 밑으로 밀린다. 시안은 동일 기능을 우선순위와 조작 위치로 정리한다. 제품 소스는 바꾸지 않는다.

## 자산과 근거
카탄: `src/ComponentArt.tsx`를 읽어 SVG로 정적 출력한다. 카르카손: `public/carcassonne-art/*.svg`를 재사용한다. 공통 명세의 public/owner/hidden, 모름값, 원본 보존, 열기만으로 턴 변경 금지 원칙을 유지한다. 명세/게임팩/개인 세션을 수정하지 않는다.

## Figma 상태
플러그인 검색은 installed:true/ENABLED. 이 작업 세션에는 Figma 작성·편집·계정 도구와 tool_search가 노출되지 않았다. Chrome은 Figma 로그인창을 보여 계정 접근 미확인. 신규 Figma 파일은 아직 만들지 않았으며 기존 파일도 수정하지 않았다. 로컬 시안과 가져오기용 SVG는 이 상태와 독립적으로 제공한다.

## 실제 렌더 후 조정
390px에서 선택 설정이 아래로 밀려 보이지 않아 선택 중 보드를275px로 줄이고 하단 조작면을 붙였다. 저장 후에는 차례와 메모를 나란히 놓아 보드와 함께 볼 수 있게 했다. 작은 부품의44px 선택 영역이 겹칠 때는 대상 선택 목록을 연다. 개인 자원은 모든 증감 버튼을 한꺼번에 펼치지 않고 해당 카드를 눌렀을 때만 편집한다. 카르카손 저장 보기에는 미플과 타일 배치 단계 표현을 쓴다.
