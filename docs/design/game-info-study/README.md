# KeepBoard · 게임 정보 중심 시안

독립 정적 시안 **1방향 / 2화면**. 제품 적용·실제 게임 기록·사진 인식과 별개다. 제품 소스/API/팩/기존 자산을 수정하지 않았다.

- **시각 방향:** 게임 클라이언트처럼 짙은 파랑 브랜드 띠와 육각 무늬, 정보 종류별 색, 짙은 게임 테이블 위의 선명한 보드.
- **정보 순서:** 게임명·기본 정보 → 선택한 저장 판 → 이어보기. 작업 화면은 공용 보드1개 → 플레이어·현재 차례 → 선택한 말의 도구.
- **조작/움직임:** 말 선택·도구 등장·저장 확인을140–180ms로 연결. 모바일은 대상 선택 후 하단 도구, 데스크톱은 오른쪽 도구. `prefers-reduced-motion`에서 애니메이션/전환을 제거한다.

## 게임 클라이언트 방향 (2026-10-21, 사용자 피드백 반영)

이전 주홍 액션과 무늬 없는 회색 배경을 버렸다. 참고 사이트 8곳의 공개 HTML/CSS에서 실제 색과 배경 처리를 추출해 방향을 정했다(브라우저 캡처 아님).

- Board Game Arena: 브랜드 파랑 그라데이션(`#0692ea → #244587`, primary `#0b72b5`)과 질감 배경 이미지
- PlayStation App: 짙은 파랑(`#003697` / `#0068bd`) + 노랑·청록·빨강·자홍 보조색
- Steam: 짙은 남색 앱 크롬(`#171a21`)
- Myludo·VLLO·보드라이프: 정보 종류마다 다른 색, 어두운 그라데이션 배너
- 미리캔버스: 진회색 + 청록 포인트
- BoardGameGeek: 403이 반환되어 참고하지 못함

**적용 내용**
- 왼쪽 메뉴: 짙은 남색 그라데이션, 선택 항목은 노란 표시
- 게임 정보: 파랑 그라데이션 위에 옅은 육각 타일 무늬를 깐 띠, 흰 글자, 보드 그림 아래 빛 번짐
- 기본 정보 색: 인원 노랑, 시간 청록, 연령 분홍
- 저장한 판: 흰 카드. 차례 표시는 그 플레이어 색, 진행 상태는 건설 청록·교환 보라. 이어보기는 파란 버튼
- 판 이어보기
  - 플레이어는 자기 색 이니셜 원과 상단 색 띠로 표시하고, 현재 차례는 노란 배지
  - 보드는 짙은 게임 테이블(남색 그라데이션 + 육각 무늬) 위에 둠
  - 선택한 말과 놓을 자리는 노랑, 저장·주요 행동은 선명한 파랑 `#1f6feb`
- 아트: `recolor-art.mjs`로 다시 칠한 선명한 보드와 말을 그대로 사용

이전 버전은 `before/`(원본)와 `before/v2-vermilion/`(주홍판 CSS·JS)에 남아 있다.

**VERIFIED (감독관 화면 확인):** 새 게임 클라이언트 테마를 시안·제품 합성 프리뷰의 홈/보드에서 각각 390×844·1440×1000으로 확인했다. 총8화면 모두 가로 넘침0·깨진 이미지0. 새 캡처는 `screenshots/game-client-*.jpg`, 기록은 [game-client-browser-verification.json](game-client-browser-verification.json)에 있다. 기존 `screenshots/library-*.jpg`·`board-*.jpg`는 주홍판 기록이다. 이번 확인은 렌더·내비게이션 범위이며 실폰·AI·원격 배포 검증은 아니다.

## 보기

현재 별도 loopback 프리뷰: **http://127.0.0.1:4372/**

```sh
node docs/design/game-info-study/server.mjs
```

- 게임 정보/저장한 판: `http://127.0.0.1:4372/#library`
- 판 이어보기: `http://127.0.0.1:4372/#board`
- HTML: `index.html` / CSS: `styles.css` / 조작: `app.js` / 별도 서버: `server.mjs`

## 작동 범위

저장한 판 선택→큰 보드 미리보기 변경, 이어보기, 말 선택→소유색 변경, 이동→점유 자리 교환, 부품 종류 선택→보드 자리 탭 추가, undo, 플레이어별 개인 수량/메모, 명시 저장→목록→재열기가 작동한다. 저장은 이 프리뷰 origin의 `localStorage` 키 `keepboard.game-info-study.v1`만 사용한다. 다른 브라우저/기기로 공유되지 않는다.

`새 판 기록`은 새 **합성 예시 판**을 여는 기능이다. 실제 사진 업로드/카메라/AI/API/인증/제품 Store 연결은 없다. 플레이어 점수·차례·중단 지점도 합성 표시값이며 자동 규칙 판정·자동 점수 계산이 아니다. 이동 가능한 몇 가지 대표 자리는 시안 확인용이며 전체 카탄 배치 엔진이 아니다. 제품의 기능 완성도를 이 시안으로 주장하지 않는다.

## 참고: 직접 확인한 범위

2026-10-21 CUA 실제 Chrome 공개 화면을 관찰했다. 외부 서비스의 화면/상업 그림은 시안에 복사하지 않았다.

|참고|직접 본 것|미확인 / 시안 적용 구분|
|---|---|---|
|[BGA](https://boardgamearena.com/)|비로그인 소개 화면의 큰 게임 아트·게임명·주 행동, 지원 게임 소개|실제 게임 테이블/플레이어/차례 UI는 직접 확인하지 못했다. 시안의 보드·플레이어·차례 구성은 의뢰의 참고 의도를 자체 설계했다.|
|[VLLO](https://www.vllo.io/?lang=ko)|공개 소개의 기능 탭/편집 도구 설명·대표 미리보기 영역|일부 동영상은 재생되지 않았다. 실제 모바일 편집기 조작·하단 도구를 직접 검증했다고 주장하지 않는다. 대상 선택 후 도구 노출은 의뢰된 패턴의 재해석이다.|
|[미리캔버스](https://www.miricanvas.com/ko)|공개 템플릿 목록·시각 미리보기·기능 소개. ‘바로 시작하기’는 가입 창으로 연결됨|가입/로그인하지 않았으며 실제 편집 캔버스 내부는 미확인. 단순 부품 팔레트는 별도 설계했다.|
|MYBOX식 보관함|직접 서비스에 들어가지 않음|의뢰된 ‘단순 목록’ 방향만 적용. 실 서비스 조사 완료로 표시하지 않음.|

카탄 인원 **3–4명**, 시간 **60–90분**, 연령 **10세 이상**은 [공식 CATAN 게임 페이지](https://www.catan.com/catan)의 기본판 표시를 확인했다(2026-10-21). 합성 예시는4명이다. 게임 정보의 출처 링크도 화면에서 열 수 있다.

아트는 기존 프로젝트 `docs/design/boardgame-companion/assets/`의 카탄 벡터18개를 이 폴더 `assets/`로 복사했다. 지형/숫자/항구/도둑을 포함한 `catan-base.svg`, 마을·도시·도로의4색, 자원 카드5종이다. 원본 파일과 `public/game-art/`는 수정하지 않았다.

## 초기 기능 검증과 최종 캡처

**VERIFIED (초기 기능 검증)** 아래 기능은 색 변경 전에 CUA Chrome에서 확인했다. 이번 색 변경은 소유색 값4개 외 JS 동작을 바꾸지 않았다. 최종 팔레트에서 감독관이 재확인한 범위는 위 기록과 같다. 아래 화면 파일4장은 최종 팔레트로 갱신했다.

- 저장 판 미리보기 전환, 저장한 판 열기/새 합성 판 진입.
- 마을 s1 지민→서준 색 변경. 점유 자리 s2와 교환 후 undo 시 원래 위치 복구.
- 마을 추가로 말14→15개, undo로14개 복귀.
- 개인 목재7장/합성 메모 입력→저장→목록→재열기에서 동일 값 확인.
- 공용 보드는 개인 기록 선택 후에도1개. 저장 후 페이지 새로고침 시 저장 상태 유지.
- 아래4화면 모두 `scrollWidth - innerWidth = 0`, 깨진 보드/말 이미지0, 주요 버튼·링크·입력 CSS 최소44px 및 DOM 반올림44px 이상 확인.
