# 필요한 관계와 불필요한 판독의 경계

2026-11-13. 공식 자료를 다시 확인했으며, 아래 내용으로 실제 사진의 판본/모드나 원사진에서 보이지 않는 값을 확정하지 않는다.

- [Sagrada 기본 공식 규칙](https://floodgategames.com/Sagrada/Sagrada-Rules-Floodgate-Games-SA01.pdf): 라운드 후 남은 여러 주사위가 같은 완료 라운드 자리에 놓일 수 있다. 따라서 주사위 개수나 보이는 띠의 순번을 실제 라운드 번호로 바꾸면 안 된다. 남은 favor는 별도 가치가 있으며 모든 토큰이 도구에 부착된 상태일 필요는 없다. 솔로/확장은 별도 조건이다.
- [Lost Cities Kosmos 공식 규칙](https://cms.kosmos.de/game-instructions/4002051694135_Lost%20Cities_Duell_Manual_web.pdf): 원정의 숫자 순서와 투자 카드 반복을 구별한다. 기본5색과6색 변형을 구분해야 한다. 증가·중복 검사만으로 증가하는 추가 카드 후보를 허위 검출로 판정할 수 없다. 숫자 규칙은 사진 정답이나 자동 값 보정의 근거가 아니다.
- [7 Wonders 공식 관리 규칙](https://rules.dized.com/game/pmaODHsUS_65I0ac8XvnoQ/Vb8L5V6lR-qPb3Fh0J30lg/phase-2-build-a-stage-of-a-wonder): 불가사의 단계를 표시하는 뒤집힌 카드는 해당 단계의 표시물이며 일반 건설 카드의 식별/효과와 구분된다. 그 카드의 숨은 이름까지 읽으려 하지 않는다. 실제 단계·겹침 관계가 필요한지는 사진과 게임 상태의 증거를 사용한다.

이 작업은 새 규칙 심판을 추가하지 않는다. 필요한 역할·순서·배치와 아직 관측하지 못한 값을 구분하는 구현/감사 근거로만 쓴다.
