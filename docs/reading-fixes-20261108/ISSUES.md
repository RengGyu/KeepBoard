시험 방식
- 자유 텍스트 완전 일치 채점이 가짜 오답을 만든다 (21건 중 12건). 비교 규칙을 다음 시험 전에 고정한다.
- 합계 %는 Rummikub에 끌려간다. 게임별 평균을 같이 본다.
- 앱 저장 단계까지의 채점이 전용 게임에서 빠져 있다.
- 사진 업로드부터 결과 표시까지의 전체 시간은 재지 않았다.

순서: 파트 1(2·10·9·11) → 파트 2(4·5·6 + 사진 8장 재시험) → 파트 3(1·3·8, 스트리밍 7은 맨 끝).

## 파트 3 결과

- 기본 판독기: Terra high + Q + 압축 v7 (`terra-high-game-observation-v1`). 사용할 수 없으면 Luna 등으로 자동 대체하지 않고 안내한다. Luna·Gemini는 읽기 설정에 남겼다.
- 제한 시간: Terra high 285초 (서버 300초 안). Luna는 240초 유지.
- 실제 앱 경로 시험 (`part3-e2e/`, 격리 저장소): 카탄 사용자 사진 Terra high 2회 약 105초, 지형 19·숫자 18·도둑 1·항구 8 동일. Luna 1회 64초, 항구 0, 상자 위치가 어긋남. 사그라다 약 64초. 초기 판이라 도로·건물 판독은 시험되지 않았다. 사진 1장 관찰이다.
- 스트리밍: Terra high만 사용. 첫 실물은 추론 뒤에 나온다(사그라다 약 42초). 이후 1초마다 읽은 수를 진행 화면에 표시한다. 끊기면 완성된 줄을 보존하고 재요청하지 않는다. 실물 하나씩 그리는 표시는 하지 않았다.

## 카탄 도로·건물 확인 (`part3-e2e/pieces-*`, 사진 1장 x 2회)

도로는 17~18개를 찾았고 사진 대조로 위치·색이 대체로 맞았다. 건물은 약하다. 1회차는 도시 4개와 종류 미상 9개, 2회차는 종류 미상 13개로 정착지·도시를 구분하지 못했다. 판 위치 연결도 1회차 75개, 2회차 51개로 흔들린다(2회차 도로 위치 미연결). AI 시각 확인이며 사람이 만든 정답은 없다.

## 빠른 수정 공통 기능 (2026-11-09)

1. 고르기: 카탄 미상 부품에도 [도로·마을·도시·없음]을 바로 표시. 일반 게임 구성물 선택에도 [없음] 추가. 범위가 정해진 작은 숫자는 한 번 눌러 선택.
2. 일괄 지정: 카탄 [전부 마을로] 후 판에서 눌러 마을↔도시 전환. 일반 게임은 선택지 4개 이하인 값이 비어 있는 같은 종류 2개 이상일 때 [전부 X] 후 눌러 순환.
3. 추가 촬영: 공통 기준(읽지 못한 부품 3개 이상이고 전체의 1/3 이상, 색·면·수량 메모는 제외)일 때 "추가로 찍어 주세요" 안내. 일반 게임 편집창에도 "이 부분 추가로 찍기".
4. 자리 추천: 이미 놓인 육각 타일·숫자로 사진과 판을 맞춰 [추천대로 놓기]. 저장된 카탄 결과 기준 도로 16/16, 건물 13/13이 모델 자리와 일치, 다른 회차 30개는 모두 추천되고 28개가 1회차 자리와 일치. 모델 결과와의 일치이며 정답 인증이 아니다.

한계: 일반 게임은 모델이 판 칸을 주지 않아 맞출 기준점이 없으므로 자리 추천은 카탄만 적용. 게임팩에서 선택지가 적은 값은 구성물 421개 중 173개이고 대부분 앞/뒤 면이다.
