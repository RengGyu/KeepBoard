# Argon–Gemini 구성물 비교 입력

`selection.json`은 앞선 48개 오류 후보에서 뽑은 **서로 다른 30개 게임의 원본 사진 30장**이다. 기존 실행기의 `cases` 형식을 유지한다. 사진·희소 참조의 실제 바이트 SHA와 사진 크기를 확인했고, 새 모델 결과를 보기 전에 30장을 모두 직접 열람했다. 모델 요청에는 사진과 현재 게임팩의 허용 범위만 사용하며, `referencePath`, 이전 응답, 기준점, 아래 체크리스트를 넣지 않는다.

선정 실패 유형: 처리 실패 4, 빈 출력 9, 부분 검출 9, 판 전체·묶음만 출력 6, 속성/필드 차이 1, 값 오류 1. 사진 범위는 공용 23, 공개 개인 7이다. 건물·연결·타일·카드·주사위·말/부대가 필요한 게임을 포함했다. 카탄 최신 사용자 사진은 별도 평가 소유이므로 여기 넣지 않았다.

`coverage-checklist.json`은 **현재** `game-photo-definitions/index.json`의 30게임 **119개 영역, 206개 영역별 구성물 종류, 624개 속성 항목**을 나열한다. 각 영역의 필드, 구성물의 수동 속성, 사진에서의 가시 여부와 수량 분모 상태도 기록한다. 선택 사진 안에서는 54개 종류에 가시 사례가 있고 그중 6개 단일 실물 종류만 좁게 개수를 확정했다. 48개 가시 종류는 전량 계수 전이며, 14개는 거리·겹침·영역 귀속 때문에 종류별 계수가 불명확하다. 1개는 선택 영역에서 식별되지 않는다. 나머지 137개 영역별 종류에는 **해당 영역으로 고정한 사진 자체가 없다**. 이것은 게임에서 그 실물이 없다는 뜻이 아니다.

`visibleObjectCountLowerBound`는 사진에서 확실히 보인 최소 수이며, 기존 3~4개 기준점은 일부 표본이라는 뜻으로만 사용했다. 상한이 `null`이면 전체 사진 분모가 없다. `not-visible-in-selected-area`의 0은 **그 사진의 선택 영역에서만** 해당한다. 속성도 기존 기준점에 적힌 값의 표본 수만 기록하며, 가려진 값·규칙상 값·개인 비공개 정보는 채우지 않았다. 수동 필드는 이미지 모델 점수에 합산하지 않는다.

따라서 이번 30회 비교로 확인할 수 있는 것은 **같은 사진·같은 선택 영역에서의 모델별 관측 차이**다. 게임 전체 저장·복원 정확도를 말하려면 다른 영역의 원본 사진과 전량 실물/속성 기준이 더 필요하다. 특히 Crew의 전시 사진, 멀리 찍힌 Castles of Burgundy·Stone Age 사진은 진행 상태의 전체 분모로 쓰기 어렵다. `additionalPhotoNeeds`는 영역별 후속 촬영 범위를 제안할 뿐, 새 모델 호출이나 추가 사진의 존재를 뜻하지 않는다.

자료 동결 확인:

- `selection.json`: SHA-256 `54f6c42322bff2d72e46c354bf0032d4f47f08daf4e88aefb599349d30f826d5`
- `coverage-checklist.json`: 체크리스트에 `selectionSHA`를 포함. 개별 사진·참조·이전 응답의 SHA와 경로는 각 게임 행에 있다.
- 원본 사진과 비공개 참조는 이 디렉터리에 복제하지 않았다. API 호출 0회.
