## 해석 경계

관측 보존과 순서 독립성은 시각적 정답률을 뜻하지 않는다. 기존 응답의 오분류·중복 후보·미배치·충돌은 그대로 검토 대상이다. 재생기의 지연은 합성값이므로 실제 공급자 속도나 30초 목표 달성 근거가 아니다. 실기기 카메라와 배포된 Workflow의 실행 한도는 이 로컬 검사로 확인되지 않는다. 이번 검증에서 유료 판독과 배포는 하지 않았다.

## 읽을 변경

- `server/scanExecution.ts`: 업로드 사진을 실행 안에서 재사용하고 단위를 동시에 판독한다.
- `server/scanObservation.ts`: 기준 관측을 유지하고 속성 충돌·미연결을 구분해 최종 그림을 만든다.
- `src/SessionWorkspace.tsx`: 유효한 작업의 부분 관측만 보여주고 완료 후 최종 결과를 불러온다.

사진 → 병렬 전송·등록 → 동시 판독 → 부분 관측 → 최종 결합 → 저장·재열기 흐름이다.
