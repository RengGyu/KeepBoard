# KeepBoard 카탄 실행판 구현 계획

Goal: 제공된 연구의 스캔 → 상황 이해 → 필요한 질문 → 저장·정리 → 재개·복원을 작동하는 앱으로 연결한다.

Architecture: React/TypeScript 모바일 대응 웹 클라이언트와 Express 공통 실행기. 선언형 게임팩은 상태 필드, 조건부 요구사항, 도출 규칙, 실물 보존 방법을 제공한다. 원본과 세션은 로컬 서버 디스크에 보관한다. Gemini/OpenAI 이미지 입력 모델을 설정해 사진을 분석하고, 키가 없을 때는 명시된 예시 또는 수동 입력으로 실행한다.

사용자 지침: 카탄 기준. 목표 기능과 성능 먼저. 검증·안전·보안의 추가 보강은 마지막. 아스트라·클로드 호출 금지. 구현솔·구현솔2·잡무루나 기존 세션으로 실행.

## 경계와 공통 계약
- 공통 자료형: shared/types.ts. 단독 소유자는 감독관.
- 구현솔: src/** (모바일 대응 UI, 연속 스캔, 근거 보기, 질문, 포장, 저장, 복원, 설정, 게임팩 화면).
- 구현솔2: server/** 중 ai/ 제외 + tests/engine.test.ts (조건 실행기, 파일 저장, REST API).
- 잡무루나: gamepacks/**, public/demo-board.svg, public/favicon.svg (카탄 팩·명시된 예시).
- 감독관: server/ai/**, 프로젝트 설정, API 클라이언트 계약, 문서, 통합 실행.

## 핵심 수용 동작
- 카메라/사진 업로드에서 원본 확보 후 필요한 상태·질문으로 연결.
- 사진에 없는 사실은 게임팩에 따른 입력으로 확보.
- 같은 게임 턴의 획득/사용 제한은 날짜·재접속으로 바뀌지 않음.
- 플레이어별 상태 입력·보기와 공용 판 상태 제공.
- 실물 묶음/용기·순서 조건을 기록하고 저장본으로 재개.
- 재개 브리핑, 원본 확대, 관계/상태 비교, 복원 순서 제공.
- API 키 설정 시 실제 모델 호출. 예시 결과는 실제 판독으로 표시하지 않음.
- 게임팩 생성/가져오기·출처·지원 공백 표시.

확인 명령: npm run typecheck / npm test / npm run build. 실행: npm run dev (4317).
