# 호출 전 사람 기준표

원본과 확대 crop을 직접 보고 고정했다. AI 출력은 아직 읽지 않았다. 정답 JSON SHA-256은 ground-truth.sha256에 고정했다.

19개 지형과 18개 숫자, 확실한 말/도로 29개 및 도둑 1개를 이미지 좌표로 기록했다. 건물은 마을/도시를 합친 building으로만 평가한다. 숫자 3/9/2는 확대 확인했다. 지형 행은 사진 좌표 기준이며 카탄 슬롯 정답이 아니다.

항구는 나무2:1, 양2:1, 벽돌2:1, 오른쪽아래 일반3:1만 확정한다. 다른 작은 항구 종류/접점은 평가 제외한다. 흰 말 하나의 모양과 전체 공급량은 불확실하다. 숨은 카드·차례·플레이어 연결은 추정하지 않는다. 정량 평가는 전체 말 정확도가 아닌 이 고정된 확실 관측의 회수율이다.
