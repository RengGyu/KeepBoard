# Terra 최소 변경 비교 · 2026-11-02

사용자가 승인한 범위: 선명한 정지 사진 안내를 기본으로 하고, 동일한 모델의 짧은 출력 형식을 최소 수정하여 비교한다.

## 변경

- `src/Capture.tsx`: 수동 사진 촬영이 기본. 자동 프레임 촬영은 체크해야 동작한다. 촬영할 영역을 크게 담고 초점을 맞추도록 안내한다. 사진 원본 해상도와 저장·전송 흐름은 유지한다.
- `server/ai/terraCompact.ts`, `terraGameReader.ts`: 선택 가능한 `literal-compact-unit-original-v3`. 게임팩에서 미리 만든 종류·속성 코드와 짧은 필드로 결과를 받아 기존 관측 형태로 복원한다. 명시적인 모름과 생략은 구분하고 원응답도 보존한다.
- 기존 v1/v2 및 카탄 전용 판독은 유지한다. 스트리밍·새 병합 정책·추가 크롭·촬영 중 분석은 이번 범위에 포함하지 않았다.

## 비교 조건과 한계

공개 실사진 원본 세 장의 동일한 바이트를 기존 v2/새 v3에 각각 전달했다. 모델 `gpt-6.1-terra`, low, high detail, 출력 한도 32768, 사진당 한 요청, 동시 최대 2개, 총 6회, 재시도 없음. 요청을 호출 전에 SHA로 고정했다. `preflight.json`과 `execution.json`에 근거가 있다.

사진은 실제 앱으로 새로 찍은 휴대폰 사진이 아니다. 기존 개발 평가와 같은 장면의 고해상도 원본이다. 사전에 고정된 부분 AI 기준만 오프라인 대조에 사용했고 모델 요청에는 기준 답을 넣지 않았다. 전체 물체에 대한 사람의 정답이 없으므로 전체 정확도·정밀도·누락률을 주장할 수 없다. 반환 물체 수가 늘어난 사실만으로 정확한 물체 수가 늘었다고 단정하지 않는다.

시간은 API 요청 시작부터 전체 응답 본문 수신까지의 실측이다. 촬영·업로드·첫 편집 결과 표시까지의 제품 전체 시간이나 스트리밍 성능은 측정하지 않았다. 조건별 1회이므로 반복 실험의 통계적 보장은 없다.

## 실측 결과

| 사진 | 기존 v2 | 새 v3 | 부분 기준 검출 v2 → v3 |
|---|---:|---:|---:|
| 카르카손 | 23.8초 | 50.3초 | 11/16 → 16/16 |
| 사그라다 | 32.0초 | 22.3초 | 21/21 → 21/21 |
| 티켓 투 라이드 | 65.1초 | 37.1초 | 25/25 → 25/25 |

매칭된 부분 기준 물체는 모두 종류가 맞았다. 사그라다의 고정된 숫자 20개는 두 형식 모두 20개 정답, 오답 0개였다. 이는 전체 사진의 모든 숫자가 정확하다는 뜻은 아니다.

카르카손 반환 물체는 v2 20개(말 17, 타일 3)에서 v3 77개(말 17, 타일 60)로 늘었다. 추가된 타일 전체의 정확성을 보증하지 않는다. 더 많은 물체를 출력하면서 총 출력 토큰은 1844 → 4257로 늘어, 전체 처리 시간도 늘었다. 사그라다는 2581 → 1719토큰, 티켓 투 라이드는 5397 → 2882토큰이었다. 짧은 형식이 물체당 출력량을 줄여도 더 많은 물체를 인식하면 전체 시간이 늘 수 있다.

## 적용 판단

수동 사진 촬영과 선명도 안내를 적용했다. compact v3는 구현 및 실제 API 수락·디코딩까지 확인했지만 선택 가능한 실험 형식으로 남긴다. 운영 기본값은 기존 v2다. 세 장·한 번의 비교와 부분 AI 기준만으로 일괄 교체하기에는 카르카손 지연 증가와 전체 정밀도 미확인이 남아 있다. 기존 형식을 빠른 척하기 위해 결과 물체 수를 제한하지 않는다. 배포는 수행하지 않았다.

선택 호출: `new TerraGameReader({profile:'literal-compact-unit-original-v3'})`. 이미 고정된 작업의 reader identity/profile은 그대로 따른다.

## 검증

관련 단위·회귀 검사 57개 통과(55개 묶음 및 추가 compact 회귀 2개): 수동 기본값/자동 촬영 선택, 전송 큐, compact 형식 복원, 값 0/false, 모름/생략, 원응답, 기존 형식, 카탄 및 크롭 병합. `npm run build` 통과. 기존 큰 번들 경고가 있다. 실제 모바일 카메라 조작은 아직 검증하지 않았다.
