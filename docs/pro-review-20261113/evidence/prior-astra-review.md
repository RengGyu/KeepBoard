# 추정 복원판 독립 검토

2026-11-12. **판정은 부분 달성이다.** 기존 보드·값 표시·선택 수정·저장 경로를 재사용한 방향은 타당하다. 다만 **구조 연결 수를 위치 정답으로 볼 수 없으며, 로스트 시티에는 확인된 관계 분류 오류가 있다.** 새 사그라다 판독의 창문 칸 복원과 실제 폰 첫 유효값·오답률도 아직 완료 근거가 없다. 제품·기존 자료는 변경하지 않았다.

## 목표별 판단

| 목표 | 판단 | 확인 근거와 한계 |
|---|---|---|
| 읽기 쉬운 원사진 구조 복원 | **부분** | 카드 크기·값 표시, 판별 묶음, 추정 표시, 정정 진입은 연결됨. 아래 관계 오류와 미배치가 남음 |
| 첫 값 30초 | **부분 / 제품 달성 미확인** | medium·low는 로컬 HTTP 미리보기 수신이 30초 이내. high는 두 사진 모두 약59초로 미달. 첫 필요한 값의 실제 화면 표시·iPhone 종단은 측정하지 않음 |
| 오답 5~10% | **미확인** | 부분 AI 기준표·일부 사진 대조뿐이다. 오독·모름·미대응·누락을 구별한 전체 분모가 없으므로 비율 산출 불가 |

## 세 게임

| 게임 | 현재 저장본 연결 / 읽힌 속성 | 독립 판단 |
|---|---|---|
| 사그라다 | 38/42 · 68/92 | 기존 18칸과 중립 패턴, 주사위 값은 읽기 좋다. 카드1·토큰3 미연결. **새 boxes 응답의 창문 주사위18개는 모두 칸 연결0**이다. 기존 화면 성공으로 대체할 수 없다 |
| 로스트 시티 | 42/42 · 115/205 | **전부 연결돼도 관계가 틀린다.** 사진상 같은 편의 파랑 줄은 near, 흰색·초록 줄은 far로 분리된다. `discard.scene`의 5개도 추정 영역은 원정 줄이다. 원래 저장 필드는 보존되지만 그림의 분류가 잘못된다 |
| 세븐 원더스 | 101/117 · 209/376 | 관측 판별·색별 묶음은 유용하다. 16개 미연결, 카드86개 중 인쇄 이름 nonnull은3개·시대 표기는0개라 판별 묶음만으로 카드 정체까지 복원됐다고 할 수 없다 |

**VERIFIED:** 원사진3장·실제 캡처6장을 직접 보았다. 로스트 시티의 오류는 저장 좌표와 `axis`/분류 계산으로 확인했다. 자동 추정은 원관측을 덮어쓰지 않고, 수동 override만 기존 저장을 사용한다. 실제6응답의 재열기/재개 값·receipt도 동일했다. 합성 수동 정정3건의 HTTP 보존은 기존 실행 보고·스크립트 근거이며 이번에 재실행하지 않았다.

가독성도 부분이다. 고정 크기 카드는 읽기 쉬워졌지만, 색줄·판 묶음이 세로로 이어진다. 제공된 844×390 비교 화면에서 로스트 시티·세븐 원더스의 실제 카드 값은 첫 화면 아래에 있다. 비교 페이지 여백과 제품 renderer의 세로 배열을 구분해야 하며, 이를 실폰 사용성 합격으로 볼 수 없다.

## 추론 강도 비교

| 게임 | high 첫 미리보기 / 완료 | medium | low |
|---|---:|---:|---:|
| 사그라다 | 59.5 / 79.5초 | 21.1 / 39.8초 | 5.6 / 28.9초 |
| 로스트 시티 | 58.5 / 75.4초 | 23.7 / 44.1초 | 3.3 / 30.7초 |

같은 게임 내 실제 body는 effort만 다르고 원사진·schema가 같았다. 6회 모두 완료, retry0, 순차 실행이며 각 조건1회다. 추정 비용 합계 **$0.158428**, 실청구 미확인.

high도 사진상 보라6을 노랑4로 읽은 사례가 있다. low는 사그라다 창문판 누락, 로스트 시티 모름93→120이 남는다. medium은 다음 판단 후보지만 **정확도 우승 근거는 없다**. 미리보기는 값이 있는 관측을 받는 시각이며, 로스트 시티는 `뒷면`만 있는 행도 자격을 갖는다. 숫자·색 등 필요한 첫 값과 최종 편집판 완료를 혼동하지 않는다.

## 다음 작업 — 최대 세 가지

1. **추정 관계부터 보완:** 기존 영역을 원정 줄로 바꾸지 말고, 대각선 판의 양쪽 분리와 새 사그라다 창문 배치를 보완한다. 완료 조건은 기존 저장 응답에서 잘못된 편/버림 재분류가 사라지고, 근거 있는 칸만 추정 표시되며 원값·정식 위치·수동값이 유지되는 것이다. 연결 수 증가만으로 완료하지 않는다.
2. **기존 renderer의 모바일 정보 밀도 조정:** 판·색줄 문맥을 유지하되 큰 미상 표기 카드·빈 줄 때문에 핵심 값이 밀리지 않게 한다. 완료 조건은 같은 원사진/저장본으로 폰에서 값 확인→선택 수정→재열기까지 가능한지 확인하는 것이다. 새 보드/시제품은 필요 없다.
3. **강도 선택을 실제 유효값·오류와 함께 판단:** 현재6응답의 대응 가능한 색·눈·숫자를 먼저 대조하고, 제품 폴링/화면 경로의 첫 필요한 값 시각을 구분한다. 완료 조건은 비교 범위의 오독·모름·누락·대기 시간이 함께 보고돼 기본 강도 선택을 설명할 수 있는 상태다. 현재 자료로 default 변경이나 전반적 5~10% 달성을 선언하지 않는다.
