# 사용자 목표와 우선순위

2026-11-13 사용자 최신 지시가 이전 보고서의 속도/출시 제안보다 우선한다.

- 사진으로 게임 중단 상태를 남기고, 읽기 쉬운 평면 판에서 실제 진행 상태를 다시 구성할 수 있어야 한다.
- 핵심은 구성물의 **값뿐 아니라 칸·양편·소속 묶음·순서·연결·필요한 겹침 관계**다. 사진처럼 작고 기울어진 썸네일이나 임의로 예쁘게 정렬한 목록은 목표가 아니다.
- 모바일 iPhone Safari를 사용한다. 가로 중심 작업면·읽을 수 있는 크기·밀어 보기·탭 정정이 필요하다. 전체 판을 폰 폭에 줄여 작게 만들지 않는다. 큰 번호로 원사진을 가리지 않는다.
- 현재 보드/아트/게임팩/정정/저장/재개 경로를 재사용한다. 새 데모만 만든 뒤 제품 구현처럼 보고하지 않는다.
- 사용자가 120종 각각의 배치 방법을 설명하게 하지 않는다. 게임팩의 영역·주소·구성물·보존 정보와 공통 구조 유형을 사용한다.
- 필요한 상태를 놓치지 않되 숨은 카드 이름·무의미한 뒷면 값·더미 아래 불필요한 개별 값까지 억지로 묻지 않는다. 장수·순서·종류만 필요한 경우와 개별 값이 필요한 경우를 구분해야 한다. 불명확하면 필요한 정보를 조용히 버리지 않는다.
- **추정 배치 허용**. 추정/수동/정식 위치와 원관측을 구분하고, 쉽게 고칠 수 있어야 한다. 추정 위치를 원문·실물 ID·확정 소유자에 덮어쓰지 않는다.
- **30초를 최우선 목표로 삼지 않는다.** 정확한 구조 복원과 필요한 값/누락을 먼저 해결하고, 속도·비용은 실제 품질과 함께 판단한다. 새 고정 시간 목표를 임의로 정하지 않는다.
- 사용자 오답 허용 방향은 5~10%지만 현재 전체 달성 실측은 없다. 오독·모름·누락·오배치·미배치를 따로 보여 주고 분모를 공개한다.
- 장기 범위는 현재 120종과 향후 확장. 현재 3종의 결함 해결을 새 게임 추가/전수 재판독으로 확대하지 않는다.
- 새 실호출을 해야만 풀리는 부분은 어떤 가설/입력/변수/횟수/비용/판정이 필요한지 제시한다. 이번 Pro 검토 의뢰 자체를 무제한 유료 호출 승인으로 해석하지 않는다.
- 불필요한 전체 검사·새 승인 흐름·규칙 심판·새 플랫폼을 추가하지 않는다. 확인한 사실, 추정, 미확인을 구분해 실행 가능한 결과를 낸다.

오푸스 원문은 검토 출발점이다. 특히 '30초 이내면 medium 채택', '세븐 원더스 지원 등급 분리'는 당시 제안이며 최신 사용자 결정/현재 제품 코드와 구분한다. medium의 장단점은 값·위치·누락을 공정하게 비교해서 판단한다. 수치만 보고 자동 전환하지 않는다.
