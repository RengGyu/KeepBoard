# 감독 수락 메모

**VERIFIED:** 아스트라 max/Normal의 진단을 검토하고 핵심 반례 7개를 직접 재실행했다. 실행 로그는 [counterexamples.log](counterexamples.log), 범위는 [verification.json](verification.json)이다. 제품 정상 검사가 아니라 현재 결함의 재현이다. 실제 저장 입력 2개와 합성 입력 5개를 구분한다.

`EstimatedGroupBody`의 grid 없는 행 분기, scene의 board 인자 누락, unsupported 추정기 반환이 retained 위치 처리보다 앞선 점, presentation이 3종 추정 결과만 소비하는 경계를 현재 코드에서 확인했다. 488개 원입력·지정 제품 해시 불변과 제품 working diff 공백도 직접 확인했다.

수락한 우선순위는 **기존 위치·표시기 복구 → 역할·관계 연결과 파생 캐시 갱신 → 팩 의미에 맞춘 표시 → 필요한 입력만 추가 확인**이다. 단순 CSS 줄바꿈이나 모든 관측을 임의 격자에 채우는 안을 완료 해법으로 삼지 않는다. 구체적인 구현 범위는 [작업 카드](../implementation-cards.md)에 있으며 아직 제품에 적용하지 않았다.

아줄 비교 PNG를 직접 열어 일부 픽셀만 담긴 것을 확인했다. DOM의 22개 수집 기록으로 이미지 전체가 보인다고 했던 이전 주장은 바로잡아야 한다. 로스트 시티 상단 잘림도 연구 보고에 남는다. 이는 저장 관측의 삭제를 증명하지 않는다. 기존 비교 이미지와 평가 입력은 이 연구에서 덮지 않았으며, 후속 실제 화면 검수 때 새 버전으로 교정한다.

연구 자료를 별도 Git 커밋으로 공개하면 HEAD는 달라져도 제품/입력은 같을 수 있다. 이를 구분하도록 감독이 `pins.py`의 HEAD 동일 여부를 `sameHead`로 분리했다. 기본 성공 조건은 지정 파일 SHA/대상 추가 없음이며, 원 연구 커밋 자체의 동일성을 강제하려면 `--strict-head`를 사용한다. 최초 아스트라의 [input-invariance.json](../input-invariance.json)은 연구 완료 당시의 기록으로 보존한다.

제품·기본값·새 provider·배포 변경은 없다. 저장/HTTP/실기기 전체를 반복 검사하지 않았다. 새 사진의 구조 판독 품질도 여전히 미확인이다.
