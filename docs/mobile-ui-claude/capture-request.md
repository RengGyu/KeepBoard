## preview 정보
- **preview:** http://127.0.0.1:4410
  - loopback 전용이며 새 임시 Store를 쓴다(합성 데이터만).
  - 키 없음, 모델 호출 0회.
  - 실행 PID는 `/tmp/kb-mui-preview.pid`(49025)에 있고, 실제 4410을 듣는 node 프로세스는 49051이다.
- **소스:** 격리 사본 `$TMPDIR/keepboard-mobile-ui-claude/app`
  - 소스 다이제스트 manifest `5598415f…`의 1337개 파일을 SHA까지 일치하게 복사했다.
  - `.keepboard`와 `.env`는 없다.
- **사진 읽기:**
  - 로컬 stub이 `/v1/aliases`에만 응답해서, 화면에는 사진 읽기가 "연결됨"으로 보인다.
  - 실제 읽기는 주입된 합성 분석기가 맡는다. 20초 뒤 합성 결과를 돌려준다.
  - 따라서 업로드하면 "읽는 중" 상태를 캡처할 수 있다. 이 경로에서는 후보가 걸러질 수 있다(조사하지 않음).
- **후보·적용 상태:** Store에 직접 넣은 합성 fixture다. 실제 AI 판독 성공이 아니다.

## 촬영 기준
- **화면 크기:** 390×844, 360×800. 가능하면 320×700 1장 추가.
- **촬영 방식:** 각 화면마다 첫 화면 1장과, 끝까지 스크롤하는 동안의 연속 캡처를 찍는다.
- **함께 기록할 값:**
  - `document.scrollingElement.scrollHeight`
  - 가로 넘침 여부: `scrollWidth > clientWidth`
- **정리:** 끝나면 viewport를 원래대로 되돌린다.
