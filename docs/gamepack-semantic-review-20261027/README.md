## 확인된 중요 문제와 반영 상태

루미큐브 원명세의 racks는 타일을 담는 받침대(board)다. 이전 네이티브 조립은 이를 unknown tile로 만들었다. 팩 정의가 아니라 [assembleObservations](../../server/ai/observationAssembly.ts)의 실물 단위 혼동이다.

**VERIFIED:** 현재 소스는 받침대를 타일/가짜 연결 생성 전에 제외하고 원관측과 경고를 남긴다. 후보 수 역시 실제 생성 객체로 집계한다. **REPORTED:** root가 rack-only 후보0 및 숫자11·주황·소유자 보존 회귀를 RED→GREEN으로 확인했다. 본 연구는 해당 시험을 재실행하지 않았다. 원명세/ID/판본/모델 프롬프트 변경이나 기존 unknown 타일 일괄 삭제는 필요 없다.

## 수정하지 않을 것

- 여러 실물을 묶은 종류명도 인스턴스·값·원본 영역을 보존하면 허용한다. 이름을 세분화하려고 팩 SHA/판본을 바꾸지 않는다.
- 카스카디아 자연 토큰, 패치워크 단추, 티켓 투 라이드 점수 등은 수동 값 경로가 있다. 사진 영역에 없다는 이유만으로 저장 누락으로 판단하지 않는다.
- 공개 개인판의 미귀속 후보와 본인 비공개 손패를 구분한다. 소유자·가려진 값·차례 이력을 사진이나 규칙으로 추측하지 않는다.
- 못 읽은 값은 ?/null로 유지한다. 모델 누락·박스 오류·모호한 평가 사진을 팩 정의 변경으로 맞추지 않는다.
