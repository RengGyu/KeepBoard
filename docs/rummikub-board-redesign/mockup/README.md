# 루미큐브 보드 시안 (모바일 390)

- 실행: `node docs/rummikub-board-redesign/mockup/serve.mjs 4400`
  - loopback 정적 서버다. 이 폴더와 `public/game-art`만 제공한다.
  - API, 사용자 Store, 키를 쓰지 않는다.
- 상태별 주소(한 HTML에서 위쪽 칩으로도 바꿀 수 있다):

| 주소 | 화면 |
|---|---|
| http://127.0.0.1:4400/#public | 공용판 |
| http://127.0.0.1:4400/#public-zoom | 공용판 · 묶음 확대와 수정 도구 |
| http://127.0.0.1:4400/#rack | 내 화면: 위에 공용판 개요, 아래 내 받침대 14개 |
| http://127.0.0.1:4400/#rack-zoom | 내 받침대 · 줄 확대와 수정 도구 |
| http://127.0.0.1:4400/#rack-empty | 받침대 첫 사진 전 ("내 받침대를 찍어 주세요") |

## 구조
- **공용판:** 테이블 면 하나에 9개 묶음을 실제 테이블처럼 줄바꿈해 놓는다. 따로 둔 타일은 점선 자리에 둔다. 묶음을 누르면 확대 시트가 열린다.
- **내 화면:**
  - 위: 공용판 축소 개요. "크게 보기"를 누르면 공용판으로 간다.
  - 아래: 내 받침대 2줄 × 7개.
  - 다른 사람의 받침대는 보이지 않는다.
- **확대 시트:**
  - 큰 타일 줄과 타일 추가 버튼
  - 색 4개(버튼에 그 색의 숫자를 표시), 숫자 1–13, 조커, 숫자 모름, 뒷면
  - 앞으로, 뒤로, 빼기, 완료
- **하단 제어:** 사진 찍기, 확대, 저장 세 개다. 공용은 "판 찍기", 개인은 "받침대 찍기"로 사진 대상을 따로 둔다.
- **비밀번호:** 개인 화면 머리말의 자물쇠 버튼으로만 건다. 걸지 않아도 된다.
- **뺀 것:**
  - 안내 문단, AI 요약, 후보 설명, 소유자 색 이름
  - 숫자 밑 색 이름
  - "이어갈 기록·보관"
  - 초록 타일

## 자산과 데이터
- **자산:** 기존 그림을 수정하지 않고 `<use>`로 불러온다.
  - `numbers.number-tile.svg`, `jokers.joker-tile.svg`, `common/rack.svg`
  - 숫자는 앱의 `rt-face-number`와 같은 방식으로 얹는다. 타일 그림 가운데의 '?' 위에 크림색 칸을 덮고 숫자를 그린다.
  - 받침대는 rack 그림을 가로로 늘려 받침으로 쓴다.
- **데이터:** 명시한 합성 데이터이며 Classic 4색(빨강·파랑·검정·주황)만 쓴다.
- **배치 방식:** 사진 좌표가 아니라 **저장된 묶음·줄 순서로 배치한 개요**다. 사진 속 배치를 그대로 재현하지 않는다. 이 구분은 화면에 길게 쓰지 않고 이 인계에만 적는다.
