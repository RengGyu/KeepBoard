## 값별 비교: 사후 사진 감사 반영

**아래는 사람 정답률이 아니라 AI 시각 기준표와의 일치율이다.** 실패한 응답은 사용 가능한 관측 0건으로 포함했다. 형식이 통과한 결과만 골라 정확도를 높여 보이지 않는다. 같은 물체의 중복 색/단어 필드는 하나의 사실로 합쳤다.

|명확한 개별 물체 대응|170/173|44/173|

추가 반환은 선정 촬영 영역의 기준 목록과 대응되지 않는 물체다. 실제 사진 밖 물체를 지어냈다는 뜻은 아니다. 위치 IoU는 상자 중첩 정도이며 판의 칸 좌표나 타일 간 연결의 정확도는 아니다.

## 전체 목록을 작성한 8장과 부분 2장

블로커스·킹도미노를 뺀 8장에서는 v2 151/154, v3 41/154개 물체가 대응됐다. v2 누락 3개, 추가 2개다. 나머지 2장은 확실히 분리되는 물체만 계산했고 수량 미상 그룹 안의 반환은 추가/오답으로 세지 않았다.

여기서 전량은 각 사진의 선택된 영역에서 확인 가능한 물체 목록이라는 뜻이다. 가려진 물체나 게임 상자의 전체 구성물이 아니다. 감사에서도 루미큐브 일부 숫자·잘린 카르카손 가장자리 등은 완전 검수되지 않았다.

## 기준표 감사와 한계

- 원래 사전 기준표와 SHA를 보존했다. 별도 Claude는 모델 출력·채점·실행 결과를 보지 않고 root 5장 사진을 확인했다. 두 장은 확대 감사, 세 장은 한 차례 원본/상자 대조였다. 완전한 사람 검수 정답은 아니다.
- 사그라다의 빠진 빨간 주사위 1개, 카르카손 특징 전사 오류 등을 사후 민감도 분석에 반영했다. 애매한 눈금/건물/자세는 모름으로 분리했다. 루미큐브 손 아래 물체는 종류를 확정할 수 없어 종류 정확도의 분모에서만 제외했다.
- root의 별도 worker 사진 확인은 모델 출력에 눈가림되지 않은 사후 확인이다. 코드네임 DAY를 GUM으로 적은 기준 오류를 바로잡고, 패치워크 노랑/주황 말 색은 불확실로 제외했다.
- 자연어 동의어와 조각 형태 정규화 중 일부는 출력 확인 후 보완했다. 이 분석은 완전히 사전 등록된 블라인드 벤치마크가 아니며, 해당 변경을 scoring-protocol.json에 공개했다.

원래 사전 기준표를 그대로 채점하면 v2 사실 305/348, v3 59/348다. 감사 반영 수치와 별도로 보관한다. 처리 성공률 10/10 대 3/10과 좌표 실패 7건은 기준표 수정과 무관하다.
